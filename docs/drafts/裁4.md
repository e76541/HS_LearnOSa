# 裁4 · 卡點填補的規則怎麼補齊（四個洞）

- 狀態：待裁
- 關聯：`裁1`（卡點判準是本案上游）、`裁3`（本案洞 3 的成敗紀錄是裁3 的量測來源）；前案＝已裁 Q2 補知參數（種子集＝卡住那格的模塊、禁外擴、補完回原位）、已裁 B-9（場次紀錄一趟一本）
- 關聯圖：
- 建議落點：[重新設計稿](../specs/2026-07-25-f3a-navigation-redesign.md) 卡點節補「填補規則」一小節（草案層，未升 canonical）

## 決策內容

要裁的問題：卡點補知循環只有「形狀」規則（觸發、種子集、禁外擴、回原位、過半叫停），「補」這個動作本身沒規則——四個洞：①補的材料是什麼；②「補完」怎麼認定；③失敗幾次記一次「看完還是不懂」；④場次紀錄怎麼記一次補知。

背景：洞 ③ 直接餵「過半叫停」的分子，不定義則叫停條件不可比；四洞不補，C-14 重跑時 Agent 沒有可執行的跑法，跑法本身就不可比。

### 選項 A — 四洞一次補齊（輕規則、草案層、暫定值可修不需重裁）

- 做法：四條各給最簡規則——
  1. **材料**＝種子集模塊的原文段重讀＋共用出題器的簡化題；允許場外查，但場次紀錄加「場外」標記（供裁2 一族後續分析）。
  2. **補完認定**＝回原格重試，由學習者自決要不要往前走——與「過站不判通過、出檢討報告自決」同一邏輯，不設判定器。
  3. **計數**＝補一輪回原格仍搭不出來，即記一次「看完還是不懂」（最簡：一輪一計）。
  4. **紀錄格式**＝場次紀錄一列四欄：格、補了哪些種子模塊、回原格結果（成／又卡）、是否場外。
  全部標草案層暫定值，比照「原地打轉 N 暫定 3、試作後修不需重裁」前例。
- 優點：C-14 重跑即刻可執行且兩次跑可比；四條全是既有裁決的同型延伸，無新機制、無判定器。
- 缺點：四條是紙上推的，重跑後大概率要改（但依暫定值前例，改不需重裁）。

### 選項 B — 只定洞 ③（計數），其餘三洞留待 C-14 重跑實證後再補

- 做法：先只寫「補一輪仍搭不出＝記一次不懂」；材料、補完認定、紀錄格式標暫掛，重跑時把實際發生的做法記下來，事後照實補規則。
- 優點：不憑空造規則，規則長在實證上（B-8 的教訓：空對空寫什麼都是猜）。
- 缺點：重跑時三個洞現場即興，跑法不可重現；「照實補規則」等於把裁量塞進試作紀錄，事後追認比事前輕規則更難稽核。

### 建議（Agent）

- 建議選：A
- 前提：四條僅落重新設計稿草案層、明標暫定值；C-14 重跑後修訂不需重裁（比照 N=3 前例）；若重跑推翻的是「形狀」而非「值」，才新開裁號。
- 理由：本案與 B-8 不同——B-8 缺的是例子（空對空），本案四洞都有同型的已裁前例可延伸（檢討報告自決、暫定值、場次紀錄層），風險是「值不準」而不是「方向猜錯」，值不準的修正成本已被暫定值機制壓到最低。

## 風險／缺點

- 選 A：暫定值一旦寫下就有慣性，重跑後若沒人回頭修，猜的值會沉澱成事實標準——C-14 結案條件應包含「回檢裁4 四條」。
- 選 B：重跑產出的「照實規則」與試作紀錄綁死，違反「試作產出不得併入正式碼」的邊界時不易察覺。
- 不裁：洞 ③ 空著，叫停條件（過半）的分子無定義，重新設計稿的環三出口實質失效。
