# 裁2 · 空位場外補過後，跨趟要不要繼承「補過了」標記

- 狀態：待裁
- 關聯：`裁1`（空位判準的下游）；前案＝已裁 B-9（場次紀錄一趟一本，不寫回模塊）
- 關聯圖：
- 建議落點：場次紀錄層規則一句（若選 B 則需另立跨場次標記存放層）

## 決策內容

要裁的問題：空位被場外補過（自己查了就懂、沒收新文本）後，下一趟同文本重算架構圖仍會標「要補參考」——這個「補過了」標記要不要跨趟繼承？

背景：空位補法有兩種——①收新文本走 F1，模塊進來、空位真消失；②場外補，原文沒變、空位永在，只是本趟記了「補過了」。B-9 已裁場次紀錄一趟一本、跨趟不繼承，本案是它在空位上的自然後果：同一空位每趟都會重新被標。

### 選項 A — 不繼承（維持 B-9 原樣）

- 做法：不動任何規則。架構圖每趟照標，學習者看到標記自行略過；真想讓它消失就走收新文本的正路（F1）。
- 優點：零新機制；把「想永久消掉空位」的壓力導向正式收錄，符合「補的材料本來就該進證據層」的方向。
- 缺點：同一空位反覆被標，趟數多了會煩；「我補過了」這件事每趟重新想起。

### 選項 B — 繼承（僅限「補過了」一個標記，升跨場次）

- 做法：另立一個跨場次的小標記層（只存「空位 × 補過了」對，不存內容、不寫回模塊），架構圖重算時讀它、把補過的空位降顯示。
- 優點：體感順；標記極小，不至於長成第二套帳。
- 缺點：立刻面對「這份紀錄算不算真值」（B-9 當時擋的正是這題）；且「補過了」沒有驗收，實質是自評——自評當真值是全倉庫一路在擋的事。

### 建議（Agent）

- 建議選：A
- 前提：C-14 重跑（補邊後同材料再走一遍）尚未發生。若重跑實證「反覆重標」真的構成阻力，屆時翻案新開裁號，帶著實證裁 B。
- 理由：B 的代價（自評當真值）是原則性的，A 的代價（煩）是體感性的；沒有實證前不用原則換體感。

## 風險／缺點

- 選 A：使用者可能用「乾脆把空位那格跳過不看」應對重標，等於標記失效——重跑時要觀察這個行為。
- 選 B：小標記層是先例，之後「還是不懂」「走到哪站」都會想比照跨場次，B-9 的邊界會被逐格蠶食。
- 不裁：Agent 實作場次紀錄時無所適從，可能兩種都做一半。
