選項預設 **A／B 兩個**（下限＝上限軟封頂）。要加 C 或更多 → Agent **先提示你**，經同意再寫入。  
每個選項必有「做法」；**優點／缺點有就寫，真沒有可不列**（勿為凑欄位硬編）。多選項要比對時再補優缺較有意義。

**不做**（除非你另要求）：選項投票／權重百分比；優缺點最低條數；實作預估時數（該案本質是排期且你點名再寫）。
