## 0. 目標主幹（本分支定稿骨架）

```
文本
  → 文本預處理
      → 前端 :: 策略導航
      → 後端 :: A. 模塊化 ｜ B. 含金量
          → F模塊
```

- **文本**：進管線的原文／來源。
- **文本預處理**：收錄、篩、清洗、分流（尚不切成 F 模塊）。
- **前端 · 策略導航**：學習怎麼走（排程、旅程、用途、提問邊界）。
- **後端 · A 模塊化**：切分／類型／邊的結構化。
- **後端 · B 含金量**：以字元／概念密度決定切法與分組。
- **F模塊**：主管線產出單元（正式或試作皆可掛此槽；細節後補）。

前後端可並行，匯流後才成 **F模塊**。

流程圖（手寫 HTML，無外掛）：[REBUILD1-flow.html](REBUILD1-flow.html)

## 4. 工作流優化（僅框層，待裁）

1. **單一進場**：文本 → 預處理，禁止草案各自再開「第二入口」敘事當主幹。
2. **前後端分流**：策略導航不寫切塊規則；模塊化／含金量不寫旅程閘門。
3. **A／B 擇一或標主**：同一文本預設一主（A 或 B），另一為輔註；細節後裁。
4. **F模塊唯一匯流**：前端路徑＋後端產物合成後才叫 F模塊；視圖／演講／R 對齊不佔主幹節點。
5. **封存／放棄框不回流主幹**（九宮、決策牌等）。
