## 0. 代號策略

### 0.1 問題

若節點寫死 `FE-*`／`BE-*`，改敘事就要整批重寫。

### 0.2 兩層代號（L）+ 橫切（SK／C）

| 層級 | 格式 | 穩定性 | 說明 |
|---|---|---|---|
| **功能層** | `L0`～`L3` | 主鍵 | 按職責，不綁前後端 |
| **步驟** | `L{n}-{nn}` | 同層可增刪 | 兩位序號 |
| **Skill** | `SK-{nn}` | 對齊 SKILL.md | 執行／投影；≠ 產物 |
| **產物** | `C{n}` 等 | ops-id-legend | hub／總圖等託管；≠ Skill |
| **別名** | 前後端等 | 可整表換 | 只作說明 |

**功能層定義**

| 層 | 職責 | 舊 a/b/c/d | 暫別名 |
|---|---|---|---|
| **L0** | 收錄：進場、標籤、分發、封存 | a | 管線底座 |
| **L1** | 流程：對齊用戶、流程化、卡點、返回 | b | 曾稱「前端」／流程面 |
| **L2** | 結構：模塊化、邊、含金量、重組 | c | 曾稱「後端·結構」／資源面·結構 |
| **L3** | 資源按需：卡點調用、跟讀材料（**無畫圖**） | d 前半 | 資源按需 |

> 規則：遷移矩陣／看板摘要用 `L*`／`SK*`／`C*`；圖上「前端／後端」只當別名。

### 0.3 禁混四系

| 系 | 範例 | 與 L 關係 |
|---|---|---|
| **草案** `D{n}`／`裁{n}` | D6、裁1 | 檔案 ID；只加「框架歸屬」 |
| **L 節點** | L1-02 | 框架協議 |
| **SK** | SK-02 | Agent 讀 SKILL.md；≠ 草案號 ≠ 作業模塊 ID |
| **產物 C*** | C1-(T3) | 託管入口；**不掛 SK 表** |
| **站位／路線** | F2、INI-001 | 舊管線／執行事項；INI ≠ L0 |
| **作業模塊** | F、T、R、V | 治理邊界 |

### 0.4 Skill 橫切（SK·執行／SK·投影）

- **SK·執行**：寫入或新增真值／產物（收錄、模塊、邊、練習、演講）。
- **SK·投影**：只展示，**不回寫** L2 模塊／邊（視圖、試跑逐步重播頁）。
- SK 不佔 L4、不進主幹必經序。

### 0.5 產物（C*）

產物表只列入口／託管。Skill **產出可入** hub；hub **本身不是** Skill。

### 0.6 L3 與 SK 的差別

| | L3 | SK |
|---|---|---|
| **是什麼** | 學習／runtime **協議節點** | Agent **讀 SKILL.md** 的作業步驟 |
| **做什麼** | 卡點時**查、組、遞**已有 L2 | **生產或投影**結構／練習／視圖 |
| **必跑 Skill？** | **否**（多數只讀庫） | **是** |
| **誰的問題** | 這個卡點要拉哪些模塊／邊？ | 誰來切文本／抽邊／出題／畫圖？ |

**L3-01 卡點調用**：依 L1-02 查 L2；輸出調用清單；**≠** 再跑 modularize／extract。  
**L3-02 跟讀材料**：組最小閱讀包 → L1-04；要新題才另觸發 **SK-06**。

| 情境 | 走 L3 | 走 SK |
|---|---|---|
| 卡住且庫已有 | L3-01→L3-02 | — |
| 卡住且無模塊 | 先 SK-02 再 L3 | SK-02 |
| 卡住且無邊 | 先 SK-03 再 L3 | SK-03 |
| 要新練習題 | L3-02 已給材料 | SK-06 |
| 要概念圖／試跑重播 | — | SK-04／SK-05 |
| 新文本進管線 | — | SK-01 |

觸發序（卡點局部）：`L1-02 → L3-01 → L3-02 →（可選）SK-06 → L1-04 → L1-05`。

**Agent 判斷四則**

1. L ＝協議位置；SKILL.md ＝怎麼做。  
2. L3 不替代 Skill 檢查表；Skill 不替代卡點／返回協議。  
3. 投影 SK-04／05 **永不**寫回 L2。  
4. F2／SK-02＝**備料**；學在 L1。
