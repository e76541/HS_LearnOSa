# 文檔整合抽取與策略多樣性

- 狀態：草稿
- 裁決來源：無
- 實作參照：無
- 後繼：無（獨立草案；**不併入**來源學習排程／OSA／F3a 現行稿正文）

## 0. 定位

描述如何把**文檔資料庫**裡的材料，經整合抽取後，在策劃與決策現場以**可追溯來源**的方式供用，並保留多種抽取／取用策略。

- **不是** canonical、**不是** 路線 INI、**不是** 作業模塊啟用提案。
- **不是** 來源佇列本體（見 [來源學習排程](2026-08-05-source-learning-schedule.md)）、**不是** 導航站位規則（見 [F3a 現行稿](2026-08-05-f3a-navigation-current.md)）。
- 本稿只管：**輪訓入庫 → 按需拉取 → 決策點出示來源**；未裁前以草案／試作名義討論，不改 `Library/規範`、不新開站位或作業模塊 ID。

## 1. 目標

| 目標 | 一句話 |
|---|---|
| 持續更新 | 文檔資料庫有固定輪訓，不靠人工一篇篇補索引 |
| 按需取用 | 策劃點或現場缺材料時才拉庫，避免全程塞全文 |
| 決策可溯 | 決策點必須顯示所用文檔與來源指標，禁止無來源斷言 |
| 策略多樣 | 抽取與取用不綁死單一打法，可依情境換策略 |

## 2. 三環流程

```text
Gemini 固定輪訓文檔資料庫
        ↓（入庫／刷新摘要或索引）
策劃點／需文件時 → 拉取資料庫
        ↓
決策點 → 顯示結論＋文檔來源
```

### 2.1 環一：Gemini 固定輪訓

| 項 | 規則 |
|---|---|
| 執行者 | **Gemini** 為固定輪訓者（本稿指定；更換須另裁） |
| 對象 | 文檔資料庫（路徑／集合待裁，見 §5） |
| 節奏 | **固定輪訓**（間隔待裁）；非事件觸發才掃描的唯一手段 |
| 產出 | 可檢索的庫內紀錄：至少含文檔 ID／路徑、輪訓時間、短摘要或索引鍵；不得只留對話暫存 |
| 禁則 | 輪訓不得改寫原文真相檔；不得把輪訓結果當 canonical |

輪訓負責**庫新不舊**；不負責當場決策。

### 2.2 環二：策劃點／需文件時拉取

| 觸發 | 動作 |
|---|---|
| **策劃點** | 規劃步驟、選路徑、組材料清單時，依當前問題向資料庫拉取相關條目 |
| **需文件** | 現場判斷「缺依據／缺原文」時，再拉一次；禁止用過期對話記憶冒充庫內容 |
| 拉取範圍 | 預設拉**指標＋摘要／片段**；全文只在策略要求或使用者明示時展開 |
| 與排程交界 | 若同時有來源佇列，拉取結果可**建議**入佇列，但本稿不定義佇列排序（排程稿另管） |

### 2.3 環三：決策點顯示與提供來源

決策點（選定方案、裁定取捨、輸出可執行下一步）必須同時具備：

1. **可見結論**（選了什麼／不選什麼）。
2. **文檔來源清單**：每條至少含可回查指標（路徑、文檔 ID、或庫內鍵）＋本次用到的片段或摘要定位。
3. **來源角色**（可選但建議）：支持／反證／背景——避免把背景材料寫成硬依據。

**禁止**：

- 決策點只給結論、不給來源。
- 以來源「很多」代替標明**實際用到的**來源。
- 用無法回查的口語指稱（「之前那篇」）代替指標。

## 3. 策略多樣性

整合抽取不綁單一策略。輪訓可產出多視角索引；拉取與決策出示時，依情境選策略（可並用，須標明本次採用哪些）。

| 策略 ID | 名稱 | 何時用 | 產出重點 |
|---|---|---|---|
| S1 | **主題聚合** | 同一主題多篇散落 | 主題簇＋代表文檔列表 |
| S2 | **對照／衝突面** | 決策前要看分歧 | 同意點／分歧點＋各自來源 |
| S3 | **最小證據包** | 只要能過門檻的依據 | 少量高相關片段＋來源 |
| S4 | **時間線整理** | 版本或事件先後影響決策 | 依時間排序的來源鏈 |
| S5 | **反證優先** | 高風險決策 | 先列反對／邊界文檔，再列支持 |
| S6 | **用途分流抽取** | 材料用途不同（知識／方法／決策／系統） | 按用途標籤的抽取結果（對齊使用迴路四用途說法，不複製其①～⑥） |

### 3.1 策略選擇規則（草案）

- 預設：策劃點用 **S1 或 S3**；決策點至少開 **S3**，有明顯爭議時加 **S2 或 S5**。
- 同一次決策可疊加策略，但輸出必須標 **策略集合**（例如 `S3+S5`），避免讀者以為只有一種整理法。
- 策略可增刪，新增須進本稿表並待裁；Agent 不得臨場發明未登記策略 ID 卻寫進正式產物。

## 4. 與既有草案的邊界

| 既有稿 | 關係 | 本稿不做的事 |
|---|---|---|
| [來源學習排程](2026-08-05-source-learning-schedule.md) | 交界：拉取結果可建議入佇列 | **不**定義佇列、時效、一主一副 |
| [使用優先學習迴路](2026-07-27-usage-first-learning-loop.md) | 交界：S6 用途標籤可對齊四用途 | **不**改 ①～⑥、使用紀錄欄位 |
| [F3a 現行稿](2026-08-05-f3a-navigation-current.md)／[OSA 現行](2026-08-05-navigation-osa-current.md) | 交界：導航決策點可套用環三出示規則 | **不**改站位、GATE／STEP、空位規則 |
| [通用文本學習工作流](2026-07-29-universal-text-learning-workflow.md) | 交界：輪訓摘要可餵 F1 九步軟訊號 | **不**當 F1 硬閘 |
| LEARNOSA／bridge | 交界：發布內容入庫後同等可被輪訓／拉取 | **不**升格內容標準 |

**獨立性**：本稿正文不併入上述任一檔；交界只以本節與 INDEX 後繼欄互指。

## 5. 待裁

| # | 問題 | 說明 |
|---|---|---|
| a | 文檔資料庫落點 | `DOC/`、獨立向量／索引庫、或外掛庫；路徑與權限 |
| b | 輪訓間隔與增量 | 全日／每 N 小時；是否只掃變更 |
| c | Gemini 介面契約 | 輸入輸出欄位、失敗重試、與其他模型分工 |
| d | 決策點 UI／產物形狀 | 僅 md 來源表、或另需畫面元件 |
| e | 與排程佇列的自動銜接 | 拉取後是否預設入佇列、誰寫入 |
| f | 策略預設組合 | 是否把 `S3` 升為決策點必做 |
| g | 試作範圍 | 先小庫輪訓＋一次決策點出示，再談升格 |

本稿未裁前：可先以**試作**名義跑小範圍（記試作紀錄），不改 canonical、不動站位、不併入最優先草案正文。
