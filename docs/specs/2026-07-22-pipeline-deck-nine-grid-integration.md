## 1. 權威管線句（提案）

```text
文本 → 模塊（拆／選）→ 牌組（固定）→ 九宮 或 牌組（隨機）
                              ↘ 測驗＋間隔重複（到期回固定牌或回宮）
```

相對 2026-07-19 句「原文 → 組件 → 模塊 →（場景）→ 九宮」的變更：

| 站 | 處置 |
|---|---|
| 文本／組件／模塊＋邊 | **沿用**證據層；組件層仍待 §12 裁決，試行可暫依 r1 或跳儲存組件（與衝突 3 同） |
| 提問＋挑選（拆選） | **併入「模塊（拆／選）」**：前沿輪探邊界、以知帶新挑選；粒度校準規則沿用流程閉環 |
| **牌組（固定）** | **新增脊柱**：依目的組最小決策子圖；模塊是牌的證據，牌不是模塊 |
| 九宮 | **降為練習／攝入呈現之一**，與「牌組（隨機）」並列，不再是唯一中段容器 |
| 牌組（隨機） | **新增練習出口**：對固定牌組或模塊池做隨機抽牌／壓力測（對齊雙階段「練習期三層隨機」精神） |
| 測驗＋間隔重複 | **沿用** explain-this 本地化；到期可回固定牌檢視或回宮 |

舊句在裁決前仍可作組件化／九宮試行參照；**新產品敘述以本句為準（待裁）**。

## 2. 各站職責

### 2.1 文本

證據入口。收錄、身份、`char_span` 規則不變。多源課群允許，來源不合併真值。

### 2.2 模塊（拆／選）

| 動作 | 沿用誰 | 要點 |
|---|---|---|
| 切分／型別／邊 | 領域規範＋組件化草案 | 模塊唯讀證據 |
| 拆 | 流程閉環規則 1 | 邊界穿過模塊→拆到可整塊會／不會 |
| 選 | 流程閉環規則 2 | 以知帶新；已知作錨 |

輸出是**候選模塊池＋邊**，不是牌、不是九宮面。

### 2.3 牌組（固定）

輸入：目的／情境＋已選模塊池（可多源）。  
輸出：`GoalSession` 的最小決策子圖（目前牌＋近端預覽）。

規則摘要（細節見導航 OSA，含 §3.7）：

- 一牌一個改路徑判斷；活棋須原文或他源模塊可指。
- 前置閘門；Guide／OptionProfile 分工。
- 選擇改後續牌；投影不回灌證據層。
- 單源嚴格 vs 多源課群由場次宣告。

**固定**＝此場次為當前目的組好的導航天線，不是永久課綱；目的變了可重組。

### 2.4 九宮 或 牌組（隨機）

二者是**練習呈現互斥選配**（同場次選一為主，另一可作輔視圖）：

| 出口 | 何時用 | 規則來源 |
|---|---|---|
| 九宮 | 要空間記憶、攝入期建圖、邊推斷 | 九宮雙階段：攝入＝假設、練習＝考卷；三層隨機 |
| 牌組（隨機） | 要決策壓力、路徑取捨、閘門演練 | 對固定牌組骰牌／骰選項壓力；禁代選高影響 |

攝入期若材料全新：可先短固定牌定位目的，再進九宮答案版走一圈（雙階段攝入規則仍適用）。

### 2.5 測驗＋間隔重複

- 題出原文、禁自評（explain-this）。
- 計時掛**模塊**；到期可觸發：回宮（九宮原面）**或**回到固定牌組重走受影響決策。
- 熟練度輔助解釋深度，不代選牌。

## 4. 與草案整合總綱六衝突

[整合總綱](2026-07-21-draft-integration-conflicts.md) 的 6 項仍待裁。本整合**不自動解消**它們，只加一條產品向約束：

| 衝突 | 與本管線 |
|---|---|
| 1 邊詞彙 | 固定牌不發明儲存邊型；只消費 canonical 邊作證據 |
| 2 九宮語義 | 九宮＝模塊面（建議維持）；隨機牌不是九宮格 |
| 3 組件未裁 | 拆選可先在模塊層操作；組件細粒度待 §12 |
| 4 hooks／fragment | 牌的 hooks 只作翻牌素材，不進邊 |
| 5 弱策略 | 約束未給的 Method → 閘門未知或不成應用 option |
| 6 試作材料 | 決策牌可用歷史／路由文章；九宮可用另材 |

## 5. 驗收（整合級，紙上即可）

1. 能指出每張固定牌的證據模塊（可跨源，來源標清）。  
2. 固定牌選擇後，後續牌有可見增刪；或非原文線停在文本邊界。  
3. 同一模塊池可切到九宮攝入／練習，**或**切到隨機牌壓力，不強制兩者同時為真值。  
4. 測驗到期能說回哪個容器（宮或固定牌）。  
5. 未啟用 M5、未改 canonical。
