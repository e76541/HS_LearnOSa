## 2. 各站職責

### 2.1 文本

證據入口。收錄、身份、`char_span` 規則不變。多源課群允許，來源不合併真值。

### 2.2 模塊（拆／選）

| 動作 | 沿用誰 | 要點 |
|---|---|---|
| 切分／型別／邊 | 領域規範＋組件化草案 | 模塊唯讀證據 |
| 拆 | 流程閉環規則 1 | 邊界穿過模塊→拆到可整塊會／不會 |
| 選 | 流程閉環規則 2 | 以知帶新；已知作錨 |

輸出是**候選模塊池＋邊**，不是牌、不是九宮面。

### 2.3 牌組（固定）

輸入：目的／情境＋已選模塊池（可多源）。  
輸出：`GoalSession` 的最小決策子圖（目前牌＋近端預覽）。

規則摘要（細節見導航 OSA，含 §3.7）：

- 一牌一個改路徑判斷；活棋須原文或他源模塊可指。
- 前置閘門；Guide／OptionProfile 分工。
- 選擇改後續牌；投影不回灌證據層。
- 單源嚴格 vs 多源課群由場次宣告。

**固定**＝此場次為當前目的組好的導航天線，不是永久課綱；目的變了可重組。

### 2.4 九宮 或 牌組（隨機）

二者是**練習呈現互斥選配**（同場次選一為主，另一可作輔視圖）：

| 出口 | 何時用 | 規則來源 |
|---|---|---|
| 九宮 | 要空間記憶、攝入期建圖、邊推斷 | 九宮雙階段：攝入＝假設、練習＝考卷；三層隨機 |
| 牌組（隨機） | 要決策壓力、路徑取捨、閘門演練 | 對固定牌組骰牌／骰選項壓力；禁代選高影響 |

攝入期若材料全新：可先短固定牌定位目的，再進九宮答案版走一圈（雙階段攝入規則仍適用）。

### 2.5 測驗＋間隔重複

- 題出原文、禁自評（explain-this）。
- 計時掛**模塊**；到期可觸發：回宮（九宮原面）**或**回到固定牌組重走受影響決策。
- 熟練度輔助解釋深度，不代選牌。
