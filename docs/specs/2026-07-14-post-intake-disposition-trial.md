# 收錄後處置 Shadow 試行設計

**狀態：** 試行；非 canonical

## 決策

外部《來源收錄後處置整合整理》是另一套 HLibrary 流程規格，不作為 HS LearnEdge 的證據來源收錄。本分支只測試可回放的人工註記與安全邊界；不把外部 `Source/*` 結構、`SourceRegistry`、只保存出口或八態流程直接納入系統。

依據：

- `Library/規範/00-設計原則.md` P6：新狀態轉移規則須先有基準證據。
- `Library/規範/10-模塊層.md` §2.5：入口三問與 `Inbox/`／DOC 分流已固定。
- `Library/規範/60-文本身份與術語.md` §7.1：`DOC/INDEX.md` 是查找入口，不是流程狀態真值。

## 對照與邊界

| 外部草稿觀點 | 本次 shadow 落點 | 不可跨越的邊界 |
|---|---|---|
| 敏感資訊前置保護 | 註記檢查器拒絕常見秘密值指派；另保留人工檢查 | 不保存、摘要或用秘密值搜尋；不自動收錄。 |
| 同一來源／保存副本／不同版本辨識 | 同資料夾 sidecar 的關聯候選 | 不重跑或合併前須人工裁決。 |
| 關聯比較、閱讀基準、差異錨點 | 記錄比較候選與理由 | 完整 `source.md` 與字元區間仍是證據；關係不可進 `edges.md`。 |
| 封存候選 | 測試矩陣的人工邊界 | 不移動、不刪除，也不把 `DOC/Archive` 視為刪除。 |

試行記錄只鏡像既有 `canonical_bucket: Review` 與 `canonical_status: needs_review`。除這些既有身份外，所有建議皆為閱讀層文字，沒有 enum、狀態儲存或轉移規則。

本工具只能讀取、驗證與回放註記。完成測試矩陣、累積基準結果並經人工裁決前，不修改 `10-模塊層.md`、`60-文本身份與術語.md`、`70-版本與裁決.md` 或 `ingest-text` Skill。
