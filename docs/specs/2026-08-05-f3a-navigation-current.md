## 1. 一句話

以終點為導向：進入 LEARN 後，先跑 **L1-03 最小可行流程**；遇 **L1-02 能力／策略卡點**才 **L3-01** 查 L2 模塊／邊、**L3-02** 組材料，走局部路徑後 **L1-05 返回原呼叫節點**。模塊化是 **SK-02／03 備料**，不是開跑前必修課。

主案例：`WORK →（裁1 路由）→ LEARN/D38 →（裁4 返回協議）→ WORK`。  
巢狀案例：`VERIFY → LEARN/D38 →（裁4 返回協議）→ VERIFY`。

## 3. 仍有效的歷史裁決（濃縮）

### 3.1 已退出（不得復活）

決策牌／前置閘門／Guide、九宮、訓練四卡、技能樹（D29 已封存）。

### 3.2 架構圖（投影）

L2 備料後可重算架構圖（**投影、不落庫**）標：要補判斷／要補參考／要練習——供 L1 開跑，**不**等於「先學完圖上每一點」。

### 3.3 WORK 外部缺口 vs LEARN 內部卡點

D48 後必須先分兩層：

| 層 | 問題 | 去向 |
|---|---|---|
| **WORK 外部缺口** | 來源／輸入不存在、工具／API／權限故障、整合失敗、所需能力供給根本不存在 | 留 WORK 排錯、替換、補來源／能力 |
| **LEARN 內部卡點** | 必要來源／工具／能力可用，但人不會操作、理解或判斷 | 進本稿 L1／L3 局部學習 |

精確的 WORK→LEARN 路由方法待 **裁1**；裁1已依 D48 重寫，不再裁舊「能不能出題／有沒有出現文字」。

LEARN 內部仍保留以下操作詞：

| 詞 | 意思 |
|---|---|
| **空位** | 當前學習來源本身沒提供需要的內容；若來源本身缺失，不能只靠重讀解決 |
| **卡點** | 資源存在但當下搭不出來；補最小 → 回原流程再搭 |
| **局部路徑** | 僅夠過該卡點的導航／跟讀／練習 |
| **返回** | 裁4已重寫：A＝補到足以重試原呼叫節點即返回；B＝LEARN 內先過局部驗收再返回；目前待裁 |

重要區分：**來源存在但 L2 尚未切模塊／抽邊**，是 LEARN 後台備料不足，可依 REBUILD1 先 SK-02／03；**來源本身根本沒有必要資訊**，則不能把「缺資料」誤診成人的能力卡點。

### 3.4 專案型過關（B-6 精神保留）

有標準答案 → 參照標準；無標準 → 預先 GATE／Goal，可衍生改版。映射為 L1 流程層級，不另開舊牌結構。

### 3.5 熟練度

導航**只產事件、不寫熟練度**；登記簿為 R 橫切。複習進誰見 **D36（L1-06 收窄）**。因此裁3不阻塞 D48／D38 第一輪主線。

## 4. LOOP 與降層（對齊 REBUILD1 §1.1）

1. 已進 LEARN 後，中級卡住：先**同層** `L1-02 → L3-01 → L3-02 → L1-04 → L1-05`。  
2. 降回 L1-03：僅**前置能力不足**且**局部修補無效**。  
3. L2 缺模塊／邊但來源存在：先 **SK-02／03**，再 L3-01——不是「卡住就當沒備料重切全文」為預設。  
4. 若發現來源／工具／能力供給本身不存在或故障，退出 LEARN，回原呼叫方處理非學習缺口；不得用更多學習迴圈掩蓋外部故障。  
5. 返回後，原呼叫節點的真實重試才是該模式的證據；LEARN 局部練習不得冒充 WORK 任務驗收或 VERIFY 證據判斷。

## 5. 不回寫

導航狀態是場次投影，**不回寫**模塊／邊真值。SK-04／05 同。

裁4若採 A，最小事件可記 `caller_mode / caller_node / learn_gap / material_ref / retry_result`，但事件紀錄不是返回 Gate，也不形成熟練度真值。
