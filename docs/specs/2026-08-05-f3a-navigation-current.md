## 0. 定位

F3a／F3b 導航的**單一現行入口**。取代決策牌-era 多稿並存；決策投影層已整層退出（C-12）。

- **不是**作業流程圖、**不是** canonical。
- 與 [OSA 現行摘要](2026-08-05-navigation-osa-current.md) 分工：OSA 管產品方向；本稿管 F3a／F3b 實作規則。

## 1. 一句話

以**終點**（文本或專案）為導向：F2 後由**架構圖**（模塊＋邊重算投影）標出要補技能／要補參考／要練習；**F3a 文本型**沿模塊團一格一題前行；**F3b 專案型**走技能書＋參考書→Gate→Goal；不會就補最小知識，仍由使用者決定是否前進。

## 2. 站位與邊界

| 代號 | 名稱 | 本稿 |
|---|---|---|
| **F3a** | 文本型導航 | 起點（架構圖許可則可隨機）→ 模塊團 → … → Goal |
| **F3b** | 專案型導航 | 起點 → 技能書＋參考書 → Gate → … → Goal |
| **F3c** | 題目 | 架構圖標「要練習」的出口；與 F3a／F3b **平行** |
| **F4** | 產出 | 講圖→演講（九宮已放棄，C-13） |

- F3a／F3b／F3c **平行可互調**，非 a→b→c 流水線。
- 模塊不改成牌；模塊是證據；導航狀態是場次投影，**不回寫**模塊／邊真值（B-9）。

## 3. 已裁決、現行有效

### 3.1 決策投影層退出（C-12）

下列**整批失效**，不得在新實作中當 F3a 主結構：

- 決策牌（`DecisionCard`）、決策前置閘門、`Guide`／`OptionProfile`
- 步的核心五型（`decide`／`q2_fill`／`reroute`／`resume_card`／`execute_next` 以牌為前提者）
- 全域最低作答形制「選項＋理由＋成立條件」、雙模式共用作答形制（縫 B）
- 訓練四卡（TextCard／NodeCard／MechanismCard／BlindSpotCard）與四判定（B-7 封存）

### 3.2 架構圖（#75）

F2 後、進站前：

```text
模塊＋邊 → 重算架構圖（投影、不落庫）
→ 標三種缺：要補技能 ／ 要補參考 ／ 要練習
→ 建 Gate 與 Goal
→ 比對技能書（登記簿）／參考書（背景模塊、hooks）
```

- **架構圖**取代舊 `gaps[]` 清單與「分層演算法」待裁項的落地形狀。
- 「分層」在此指**依賴邊算出的高度層**（篩「這篇太高」），與組件**粒度層**（原文→組件→模塊）不同，兩者不互斥。

### 3.3 文本型核心詞（重新設計稿採納部分）

| 詞 | 意思 |
|---|---|
| **空位** | 原文沒寫這塊（＝問／邊界 B2「原文未展開」；不新造欄位） |
| **卡點** | 文本有但你搭不出來；補一小塊→回原位→再搭 |
| **站** | 模塊團；起跑前切好（非 emergent 走出來才封） |
| **一步** | 一格一題；組裝驗收題**不計步**（比照舊前置閘門） |
| **過站** | 逐條檢討報告；由學習者自決是否前進（不判「通過／不通過」） |

### 3.4 專案型過關（B-6）

| 類型 | 規則 |
|---|---|
| **6-A 有標準答案** | 以參照標準（如標竿網站）作唯一評價基準 |
| **6-B 無標準答案** | 開始時設 GATE 數與 Goal；途中不合理可改版為 GATE1-A 等衍生號 |

### 3.5 技能書與熟練度（A-1、A-2、B-10）

- **技能書**＝登記簿名冊型索引（非樹形先驗設計；canonical 6.1「不是樹」仍成立）。
- 導航**只產事件、不寫熟練度**；半自動 10 引用＝1 點由 canonical v0.3 r7 管，人工為最終真值。
- 參考書＝非技能的詞（背景模塊、`is_skill_signal`＝否）；小故事≈hooks（A-3 留空值）。

### 3.6 起終點（B-8）

- **起點**：使用者決定或 Agent 建議；非完全隨機——分層就緒後取當層之一（B-11 待分層設計細化）。
- **終點**：看完架構圖並篩選後決定 Goal（非「以整篇文本為終點」）。

## 4. 與 Q 引擎、循環思考的接點

- **Q1**（探邊界、校粒度）：保留現行語義，掛 F2 拆選旁路。
- **Q2 補知**：觸發從「卡決策牌」改為「卡某一格」；共用前沿輪出題器，參數改種子集，**禁外擴、補完必回原位**（沿用已裁 Q1／Q2 參數分離）。
- **循環思考四步**：第三步「定缺口」改讀作「定**卡點**」。
