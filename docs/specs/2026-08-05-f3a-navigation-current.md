## 3. 仍有效的歷史裁決（濃縮）

### 3.1 已退出（不得復活）

決策牌／前置閘門／Guide、九宮、訓練四卡、技能樹（D29 已封存）。

### 3.2 架構圖（投影）

L2 備料後可重算架構圖（**投影、不落庫**）標：要補判斷／要補參考／要練習——供 L1 開跑，**不**等於「先學完圖上每一點」。

### 3.3 空位／卡點（操作定義；細節待裁）

| 詞 | 意思 |
|---|---|
| **空位** | 原文沒寫這塊 |
| **卡點** | 文本有但當下搭不出來；補最小 → 回原流程再搭 |
| **局部路徑** | 僅夠過該卡點的導航／跟讀／練習 |
| **返回** | 通過後立刻 L1-05，不滯留複習堆 |

精確定義與計點 → **裁1～4**（待裁；開跑試作可用暫定操作定義）。

### 3.4 專案型過關（B-6 精神保留）

有標準答案 → 參照標準；無標準 → 預先 GATE／Goal，可衍生改版。映射為 L1 流程層級，不另開舊牌結構。

### 3.5 熟練度

導航**只產事件、不寫熟練度**；登記簿為 R 橫切。複習進誰見 **D36（L1-06 收窄）**。

## 4. LOOP 與降層（對齊 REBUILD1 §1.1）

1. 中級卡住：先**同層** `L1-02 → L3-01 → L3-02 → L1-04 → L1-05`。  
2. 降回 L1-03：僅**前置能力不足**且**局部修補無效**。  
3. L2 缺模塊／邊：先 **SK-02／03**，再 L3-01——不是「卡住就當沒備料重切全文」為預設。

## 5. 不回寫

導航狀態是場次投影，**不回寫**模塊／邊真值。SK-04／05 同。
