## 動機

PDF 等專業課程公式、定義、步驟密度高,人事時地物稀薄;現行「模塊+九宮」下,切出的模塊無「畫面」可入宮,需求無法負荷。需補子模塊粒度的「組件」層,並把「成畫面」的要求從模塊完整性移到呈現層(場景)——專業知識無人事時地物仍可為完整模塊。

## 整合管線(權威敘述)

三份草案共用同一條管線;本節為現行敘述。雙階段草案與流程閉環草案的對應句已同步改寫,舊寫法「文本 → 模塊層 → 九宮」作廢。

```text
原文 → 抽組件 → 組裝模塊(+邊,完整性檢查)
              ⇄ 提問(前沿輪;拆併回饋到組件)
              → 挑選(以知帶新)
              → 成景(渲染時計算,不落庫)
              → 九宮(攝入期 → 練習期)
              → 測驗+間隔重複 ──到期≥3──→ 回原面
                    │
                    └── 第二循環起提問站為主閘門
```

分層簡式(儲存層 vs 視圖):

```text
原文 → 組件 → 模塊 → 九宮
              ↘ 場景 = 模塊 + 有邊相連的背景模塊/素材(渲染時計算的視圖,不落庫)
```

- **不跳層**:不得略過組件直接從原文跳到九宮;場景不是儲存層,故「跳過場景以模塊入宮」合法(無背景可配時)。
- **雙階段規則照舊**:攝入期答案版照講一圈;練習期三層隨機逐級開;回宮用原面,經拆併對不上才重排。
- **流程閉環規則照舊**:提問探邊界、挑選以知帶新、測驗掛模塊、原面優先;攝入期第一輪提問站只輕量探先備知識。

## 組件(fragment)

- **獨立節點**(裁量①:可跨用):`component_id / source_id / char_span / kind`。
- kind 閉集(暫定):定義|公式|條件|步驟|證據|例子|背景片段。
- 唯讀證據層;不進邊層、不進對齊、不生成熟練度(沿用 2.1a 隔離原則)。
- 跨用方式:本體錨定原生來源 char_span,他處以**引用**使用;等級記在引用關係上,不記本體。
- **待補(裁決前)**:引用關係的儲存位置與結構(獨立表／模塊側清單等)——等級制推導重算的地基,未定則 L1「已掛上某命題」無從機械執行。

## 等級制 assembly_level(變動制)

```text
L0 孤立碎片 → L1 已掛上某命題 → L2 已組成完整模塊 → L3 場景就緒可入宮
```

- 等級屬於「組件×組裝」關係,由組裝狀態(及引用關係)**推導重算**,不手設、不儲存於組件本體。
- 同一組件在不同組裝可有不同等級(跨用的自然結果)。
- L3 出口=挑選後成景可入宮;無背景可配時以完整模塊直接入宮仍算 L3。

## 模塊完整性(機械檢查,不加新規則)

完整性判準直接取現行四型別本體必填欄位:

| 型別 | 完整條件 |
|---|---|
| TeachingModule | concept_core + examples |
| MethodModule | preconditions + procedure + constraints |
| CaseModule | context + actions + outcome |
| AnalysisModule | claim + evidence + assumptions |

- 欄位值「作者未給」視為已填(依 2.3 另受弱策略點限制;不擋入宮)。
- 未完整者停留在 L1 以下,不得入宮。
- 試作時統計「靠『作者未給』過關」比例,供日後是否收緊放行規則。

## 場景與九宮格位(裁量②)

- 場景 = 模塊 + 有邊相連的背景模塊/素材,渲染時計算,**不是儲存層**。
- 人事時地物是「場景」的判準,不是「模塊」的判準。
- 格位內容:**場景優先**;無背景可配之模塊(純機制、公式鏈)可直接以模塊入宮。

## 組裝觸發:雙軌(裁量③)

1. **管線軌**:模塊化時自動抽組件並組裝一次。
2. **提問站軌**:前沿輪回饋「一半會一半不會」→ 拆到組件重組——即流程閉環規則 1 拆併校準的細粒度落點。

**本次試作範圍**:只跑管線軌。提問站軌依賴流程閉環口頭驗證,不在 `module-fragments-nine-grid` 成功判準內。
