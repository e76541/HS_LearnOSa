## 1. 需求原文（原樣收錄）

> 我會把它收斂成一套簡單且可重複使用的方法，不綁定任何產業。
>
> ### 通用文本學習工作流（最終版）
>
> **0. 定義問題（Problem）**  
> 作者真正想解決什麼問題？避免一開始就陷入細節，而是先抓住核心目的。
>
> **1. 蒐集證據（Evidence）**  
> 作者用什麼證明自己的觀點？包括：數據、案例、實驗、推理、引用文獻。先看證據，再決定是否接受結論。
>
> **2. 抽象原理（Principle）**  
> 把具體案例抽象成可重複運用的原理。例如：牛棚調度 → 資源配置；股票停損 → 風險管理；AI Prompt → 決策流程。找出跨領域都適用的共同機制。
>
> **3. 建立框架（Framework）**  
> 把原理整理成結構化流程。例如：流程圖、決策樹、Checklist、SOP、Prompt、Workflow。讓知識不只是理解，而是可操作。
>
> **4. 找出邊界（Boundary）**  
> 這套方法什麼時候有效？什麼時候失效？有哪些限制與風險？這一步能避免把方法神化，也是知識真正成熟的重要標誌。
>
> **5. 模組化（Module）**  
> 把框架拆成可獨立重用的能力。例如：資料取得 → 資料清洗 → 特徵建立 → 模型 → 評估 → 輸出。未來換任何領域，只需要替換部分模組，而不是全部重學。
>
> **6. 驗證（Validation）**  
> 自己是否能重現？包括：實作、回測、練習、案例測試。不能驗證的知識，只能算理解，不能算真正掌握。
>
> **7. 知識輸出（Teaching）**  
> 把自己的理解輸出。例如：教學、寫文章、演講、製作教材、建立 AI Agent。如果能讓別人理解，代表自己的理解通常也更加完整。
>
> **8. 回饋迭代（Iteration）**  
> 根據實作與他人的回饋，修正：哪裡理解錯？哪裡規則不足？哪裡需要新增模組？哪裡可以優化？再回到第一步，形成持續循環。
>
> ### 最後濃縮成一句話
>
> 定義問題 → 蒐集證據 → 抽象原理 → 建立框架 → 找出邊界 → 模組化 → 驗證 → 知識輸出 → 回饋迭代。
>
> ### 核心精神
>
> 這套流程的目的不是記住知識，而是把任何知識轉化成可驗證、可重複、可遷移、可持續優化的方法。  
> 也就是說，你學到的不只是某個答案，而是一套能在不同領域反覆運用的思考與建構流程。

## 2. 掛點：F1 入口篩選軟建議

| 項 | 約定 |
|---|---|
| 掛點 | **F1** 入口：`Inbox` 新文字進管線、跑完 `module-layer` §2.5 **入口三問之後**、正式候選分流／轉桶之前 |
| 性質 | **軟建議**（多值、非硬綁）；不得因建議覆寫三問出口（棄置／正常來源／一次性素材） |
| 觸發 | 入口三問判定為「正常來源」或「一次性素材」時輸出；入口淘汰可省略（無學習價值可建議） |
| 輸出 | 九步各標 `有｜弱｜無`＋一句白話；末附「建議下一步」1～3 條 |
| 落檔 | 可選寫入 Inbox 文檔 `README.md` 的「學習工作流建議」節，或對話回報即可；**沒有不算缺檔** |
| 禁區 | 不進 ModuleCore；不新建 enum／狀態轉移；不取代候選分流 `retention`；不對股價做預測（記憶禁項） |

### 2.1 建議輸出最小形

```text
## 學習工作流建議（軟建議）

| 步 | 代號 | 文本覆蓋 | 一句話 |
|---|---|---|---|
| 0 | Problem | 有｜弱｜無 | … |
| 1 | Evidence | … | … |
| 2 | Principle | … | … |
| 3 | Framework | … | … |
| 4 | Boundary | … | … |
| 5 | Module | … | … |
| 6 | Validation | … | … |
| 7 | Teaching | … | … |
| 8 | Iteration | … | … |

建議下一步：
1. …
```

### 2.2 判讀提示（給 Agent，非硬規則）

- **Problem 無／弱**：作者目的不清 → 建議先用一句話重述「這篇想解決什麼」，再決定是否深讀。
- **Evidence 弱、結論強**：建議先核對證據再接受原理，避免把敘事當方法。
- **Principle／Framework 有、Boundary 無**：標為成熟度缺口；建議主動問「何時失效」。
- **Module 有**：提示可與後台模塊化（F2）對齊，但**不強制**先切模塊才給建議。
- **Validation／Teaching／Iteration**：多為讀者側下一步；文本未寫不代表淘汰，只標「需自建」。
