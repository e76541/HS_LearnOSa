## 1. 一句話

真實目的發生時，組**最小決策路徑**；不會就補**最小知識**；使用者自己選，選完改路、再導航。

## 2. 站位

| 代號 | 名稱 | 本抽出 |
|---|---|---|
| **F3a** | 策略 V2／最小一步 | **導航模式**（另有訓練模式，本稿不展） |
| 作業模塊 | **F** | 不另開 M5 |

## 3. 導航循環（最小一步）

```text
真實目的
→ 必要判斷
→ 能選就選／不能則補最小知識再選
→ 選擇改變後續牌組
→ 執行下一步
→ 再定位
```

## 4. 三層（導航視角）

| 層 | 物件 | 責任 |
|---|---|---|
| 證據層 | 模塊／邊／字元區間 | 真值；牌的依據 |
| 決策投影層 | DecisionReadiness、Guide、OptionProfile、DecisionCard | 能否決定、考量、方案、影響 |
| 導航控制層 | GoalSession、Deck、RouteState、DecisionRecord、DecisionReview | 組牌、位置、分支、結果 |

邊界：**模塊不是牌**；牌是導航介面；牌組是情境生成的路徑。

## 5. 入口門檻

文本進導航＝**活棋**（選項來自原文支撐）＋**決策前置閘門**通過。  
TextCard A–E **不是**導航入口條件。

### 前置閘門三出口

1. 資訊與權限足夠 → 展開考量與方案比較  
2. 資訊不足但可等待 → 先查證  
3. 資訊不足且不能等待 → 強制風險決策（明示假設、監測、退路）

## 6. 決策牌（正面／翻牌）

**正面**：要決定什麼；為何現在；尚缺事實／能否決定；可能漏想的考量；確認後才出選項與主要影響。  
**翻牌**：條件、風險、可逆性、完整影響、課程依據、「不會選」診斷入口。

**全域最低作答**：選項＋理由＋成立條件（`completion_rule` 只可加嚴）。  
系統可建議，但**高影響／不可逆不得代選**。

## 7. 卡住時（Q2）

無法完成某張牌 → 診斷該決策的**最小知識前沿** → 只補對應模塊 → **必須回到原牌**再選。  
診斷前不先給建議答案。

## 8. 與訓練模式的分界（只標界，不展訓練）

| | 導航 | 訓練（不含於本頁） |
|---|---|---|
| 主物件 | DecisionCard／GoalSession | TextCard→NodeCard→對照 |
| 作答 | 選項＋理由＋成立條件 | 選擇＋可檢驗機制假設 |
| 歸因 | Review 只管預期 vs 實際；需歸因走升級口 | 四判定專屬 |

## 9. 刻意不做

- 不要求先學完才開始任務  
- 不把固定課綱改名為牌組  
- 不代選高影響決定  
- 不把一次情境路徑回寫成通用知識真值  
- 本抽出不修改 canonical、不開路線 INI
