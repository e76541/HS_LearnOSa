# 演講備課圖譜互動（隨機選取 × 自由移動）

日期：2026-07-15
狀態：草案
裁決來源：無
實作參照：無（規格草案）
後繼：[knowledge-visualizer-design.md](./2026-07-13-knowledge-visualizer-design.md)（INI-005 Phase 1）、[modular-visualization-trial.md](./2026-07-15-modular-visualization-trial.md)

關聯 Skill：`.agents/skills/run-speaking-session/SKILL.md`

## 問題

學習管線含 **演講場次**（備→講→問→記）。使用者希望在模塊圖上增加：

1. **隨機選取模塊**（探索／熱身／備課）
2. **自由移動模塊**（自訂版面、調整視角）

需與 canonical 演講規範（合規鏈、P8 封閉世界）對齊，並與既有視覺化路線（INI-005／Archify 試作）銜接。**不開新路線 INI。**

## 規範邊界（必讀）

來源：`Library/規範/30-練習層.md` §4.2a、`run-speaking-session` Skill

| 規則 | 對本需求的約束 |
|---|---|
| 一次場次 = 一條 **合規鏈** | 正式「講」不得隨機跳模塊；一頁一模塊、換頁 = 一條邊 |
| P8 **禁止隨機走圖** | 隨機僅可用於抽圖式／子圖實例；**不能**無邊亂逛當正式演講 |
| 第三幕「問」 | 問題池可窮舉後 **依規則抽取**（非隨機走圖） |
| 視圖不回寫真值 | 拖曳版面不得寫入 `modules.md`／`edges.md` |

## 雙模式設計（草案）

```text
模塊圖 UI
├── 備課／探索模式（本 spec）
│   ├── 隨機選一個模塊 → 高亮 + 流向面板 + 詳情
│   └── 拖曳節點 → 位置存 session／localStorage（投影層）
└── 演講模式（既有 run-speaking-session）
    ├── 選定一條合規鏈 → 鎖順序
    └── 輸出投影片（一頁一模塊）；評分走語義三維
```

**隨機選取**在備課模式：從當前來源有效技能模塊均勻抽樣（可排除 `background`）。  
**自由移動**只改顯示座標，不改模塊語義、邊型別或方向。

## 載體可行性

| 載體 | 隨機選取 | 自由移動 | 演講鏈銜接 |
|---|---|---|---|
| Archify + enhance（現試作） | 可加小按鈕（快） | ❌ SVG 固定座標 | 僅備課原型 |
| `tools/viz` Phase 0 | 腳本／Agent 生成 | ❌ Mermaid 靜態 | inline 快查 |
| **INI-005 React Flow** | ✅ 按鈕 + 鍵盤 | ✅ 原生拖曳 | **正式路線** |

長期實作掛 **INI-005 Phase 1** 擴充；Archify 試作可選做「隨機跳詳情」最小原型驗證需求。

## 成功條件（草案）

- 備課模式可隨機選模塊並顯示上游／下游／`char_span` 摘要
- 節點可拖曳；重新整理後可選擇恢復預設布局或讀取本機快取
- 切換演講模式時：從圖上選鏈或匯入合規鏈 id，**鎖定順序**，不再隨機／拖曳改語義
- 正式場次評分不混入備課模式的隨機瀏覽行為
- 所有顯示可溯源 `module_id`；不回寫正式資料

## 刻意不做（草案）

- 拖曳改邊或改模塊歸屬
- 正式演講中隨機走圖
- 新建路線 INI（併入 INI-005 與演講 Skill 生態）
- 本階段不實作投影片自動匯出（留待演講模式整合）
