## 0. 定位

依**來源**（文本／文檔）安排**哪篇先處理、何時再碰、是否複習**。使用者 2026-08-05 列為現行優先事項。

- **不是** canonical、**不是** 路線 INI、**不是** 作業模塊啟用提案。
- **上下游**：本稿管**入場**；[使用迴路](2026-07-27-usage-first-learning-loop.md)管入場後 ①～⑥——兩者不重疊。
- 未裁前以**草案**名義試作；不改 `Library/規範`、不新開站位或作業模塊 ID。

## 2. 來源佇列

### 2.1 佇列單位

- 排程對象是**來源**（一篇文本、一份 DOC 修訂、一則 LEARNOSA 發布內容），不是單一模塊。
- 佇列是**前台消化順序**；F1／F2 後台批次處理不另排程，但不阻塞佇列中的下一篇開跑（對齊使用迴路「索引不卡關」）。

### 2.2 入佇列

| 觸發 | 動作 |
|---|---|
| Inbox／DOC 新文本 | 預設入佇列尾端 |
| LEARNOSA 發布→F1 | 同樣入佇列；L1 試行類預設時效＝半衰（見 §3） |
| 使用紀錄「結果＝不符」 | 該來源**回佇列**（事件驅動，非日曆） |
| 整理輸出「下一步＝深讀／進使用迴路」 | 升優先或直送主圈（見 §2.4） |

### 2.3 排序訊號

佇列排序用**多訊號**，不發明新 enum；主要訊號：

1. **整理四欄的「下一步」**（停止｜建索引｜深讀｜進使用迴路）——來自使用迴路 §1.1。
2. **時效**（§3）——快訊可插隊；長效可沉底。
3. **F1 九步覆蓋表**（Problem…Iteration 各 `有｜弱｜無`）——覆蓋高（Problem／Evidence／Boundary 皆「有」）者優先深讀或進使用迴路；覆蓋弱者降為「建索引」即止。
4. **使用者明示優先**——覆蓋自動排序。

**禁止**：用模塊數、熟練度點數或 SM-2 間隔當預設排序（與 OSA 母稿「間隔重複移出核心」及使用迴路 §6.3 懸空裁號一致）。

### 2.4 前台節流：一主一副

佇列再長，同時推進的使用迴路仍受 **一主一副**（使用迴路 §5.1）約束：

- 排程只決定**下一個主圈**換哪個來源。
- 副圈至多一個，且不得進④套用。
- 快訊插隊可佔副圈做①～③，不得同時佔兩個④。

### 2.5 出場規則

佇列中來源**超過 30 日未有任何前台動作**（無整理輸出、無使用紀錄、無 qna）→ 自動降級：

- 預設動作：**建索引**或**封存**（不再佔優先序）。
- Agent 可提醒一次；使用者確認「放棄」則移出活躍佇列，保留 DOC／索引指標。

## 3. 時效分級

在整理輸出（使用迴路 §1.1 四欄）加第五欄 **`時效`**，三值封閉集：

| 值 | 定義 | 排程行為 |
|---|---|---|
| **長效** | 原理、方法、結構判準；一季後仍可用 | 正常排序；複習僅靠 §4 事件觸發 |
| **半衰** | 版本、市場、工具鏈、政策類；約一季內仍可信 | 被引用或進使用迴路前**重跑 §1.3 使用前證據驗證** |
| **快訊** | 新聞、快報、當日資訊；過期即棄 | **可插隊**；**不排複習**；過期自動降級為索引或刪出活躍佇列 |

**規則**

- 時效是**排程欄位**，不進 ModuleCore、不寫入技能登記簿。
- 未標時效 → 預設 **長效**（少問、可開工）。
- LEARNOSA L1 試行發布 → 預設 **半衰**，除非驗證項目明示長效。

## 4. 複習與再觸發

**原則**：複習綁**使用事件**，不綁日曆式 SM-2（與 explain-this 模塊粒度 SM-2 試行、使用迴路主路徑分離）。

| 觸發 | 動作 |
|---|---|
| 使用紀錄「結果＝不符」 | 來源回佇列；可保留原使用紀錄，新一圈另記 |
| 使用紀錄標「要練習」或 `practice-ready` 累積 | 喚醒 **F3c**（按需，非每篇必做） |
| 半衰來源被引用／跨情境套用 | 強制重跑使用前證據驗證（使用迴路 §1.3） |
| 快訊過期 | 不複習；降級或移出 |
| 使用者明示「要複習」 | 該來源升優先進主圈或副圈①～③ |

**選配（非預設）**：使用者對已標「要練習」的來源可開**輕量日曆提醒**；不得對全佇列或快訊預設日曆排程。

## 5. 大量文本

1. **禁止**對大量文本逐篇強制進使用迴路或補造情境。
2. 預設路徑：批次走 **§1.1 整理入口** → 四欄＋時效 → 「停止／建索引／深讀／進使用迴路」分流。
3. 只有「下一步＝進使用迴路」者才進主圈；其餘沉索引或封存。
4. 文本大到 **② 選不出情境** 時，排程可標記「建議開 F3a／F3b」（按需，見 [F3a 現行稿](2026-08-05-f3a-navigation-current.md)），仍受一主一副約束。
5. 九步覆蓋表可批次產出（F1 軟建議），作為排序訊號，不作淘汰硬閘。
