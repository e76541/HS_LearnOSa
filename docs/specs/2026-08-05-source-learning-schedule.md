## 4. 複習收窄（核心 · 對齊 REBUILD1 §1.2）

**只**下列進入重度學習＋間隔複習：

| 條件 | 說明 |
|---|---|
| **高頻** | 多個卡點／多趟 L1 反覆碰到 |
| **核心** | 不過則 L1-02 無法做精確判斷（名詞延後的反面：現在需要） |
| **反覆出錯** | 局部路徑／練習（SK-06）連續失敗 |

其餘 L2 模塊維持**後台資源**，不預設進複習佇列。

| 觸發 | 動作 |
|---|---|
| 過收窄門檻 | 來源或相關模塊組進複習候選 |
| 可選 SK-06 | 只對收窄後的集合出題 |
| 快訊過期 | 不複習 |

**選配**：使用者對已收窄項可開輕量日曆提醒；禁止對全佇列預設日曆。
