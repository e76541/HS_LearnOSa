## 1. 目的轉向（仍有效）

**舊（已廢）**：文本 → 逐模塊學完 → 練習 → 熟練 → 演說  

**新（REBUILD1）**：

```text
真實目的
→ L1 大／中／小流程＋策略卡點
→ 先跑最小可行
→ 卡點才 L3 調 L2 模塊
→ 局部路徑（可選 SK-06 練習）
→ 返回原流程
```

終點：使用者在真實任務中能作有依據的判斷並取得可執行下一步。

## 2. 兩層（對齊 L／SK）

```text
L2 證據層（模塊／邊；SK-02／03 備料）
→ L1 流程控制（Goal／流程層級／卡點／RouteState）
→ L3 按需調用（查庫組包，≠ 重切）
```

- 模塊是**證據與彈藥**，不是預設必學課綱。
- 路徑是情境生成的**子圖**，不回寫 L2 真值。
- 視圖用 **SK-04／05 投影**＋產物 C*；不是 L3。

## 3. 刻意不做

- 不要求先學完所有模塊才開跑。
- 不由 Agent 代作高影響決定。
- 不把一次情境路徑寫回通用知識真值。
- 間隔重複**不進核心**；複習收窄見 [D36](2026-08-05-source-learning-schedule.md)（L1-06）。
- 不復活九宮／決策牌／技能樹（D29 已封存）。
