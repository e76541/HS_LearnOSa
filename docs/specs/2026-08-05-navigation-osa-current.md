## 1. 目的轉向（仍有效）

**舊**：文本 → 模塊／邊 → 練習 → 熟練 → 演說  

**新**：真實目的 → 定位情境 → 必要判斷 → 能判斷則選擇／不能則補最小知識 → 執行下一步 → 重新定位  

終點是**使用者在真實任務中能作有依據的選擇並取得可執行下一步**；學習改為導航中的按需能力。

## 2. 現行兩層（決策投影層已移除）

```text
證據層（Source、Module、ModuleEdge、SkillNode）
→ 導航控制層（GoalSession、Gate、RouteState、架構圖投影）
```

- 模塊是牌的**證據**，不是導航介面本身。
- 動態路徑是情境生成的**子圖**，不是固定課綱。

## 3. 刻意不做（仍有效）

- 不要求先學完課程才開始任務。
- 不由 Agent 代作高影響決定。
- 不把一次情境路徑回寫成通用知識真值。
- 間隔重複**移出核心**（複習改由 [來源學習排程](2026-08-05-source-learning-schedule.md) 事件驅動）。

## 4. GRILLME／前沿輪（重定位）

在使用者**無法完成當前導航格**時，診斷該步所需的最小知識前沿；補知後**回到同一格**，不以「看過內容」視為完成。題目與講解須有課程證據。
