# 含金量字元製模塊與同分組表

- 短代號：D46
- 狀態：草稿
- 裁決來源：無
- 實作參照：[2026-08-05 LLM Wiki 試作](../experiments/2026-08-05-d46-llm-wiki-spike.md)

## 0. 定位

把「以當下文本定義的含金量 → 做成**文本模塊** → 依規範落檔 → 同定義／同背景／同狀況另表繪製」從 D39 與既有導航交界中**抽出**成獨立草案，**先測效果**。

- **不是** canonical 改寫、**不是** 路線 INI、**不是** 作業模塊啟用提案。
- **不是** D39「知識塊」（知識塊≠模塊）；本稿目標是做出**合規文本模塊**。
- **不是** F3a／OSA 站位規則本體；可對照導航，但不改 GATE／STEP。
- 未裁前僅**草案＋試作**；正式模塊若寫入 `DOC/`，須另符合現行 [領域規範](../../Library/CURRENT.md)（模塊層等），失敗則停在試作紀錄。

## 1. 目標（先測）

| 目標 | 一句話 |
|---|---|
| 含金量切塊 | 以**當下文本自己定義**的計量單位與粒度為含金量，據此製成模塊候選 |
| 規範落檔 | 成為模塊後，**依原本規範**記錄（欄位、證據、ID 等） |
| 同分組表 | 後續將**同定義、同背景、同狀況**者，**單獨繪製表格**（一組一表） |
| 先測效果 | 以試作回饋改草案；不硬升格 |

## 2. 三步流程

```text
當下文本 → 抽出「計量單位＋切塊粒度」契約 → 切／併成模塊候選
        → 依 canonical／技能 寫成正式模塊紀錄（試作可不配正式 ID）
        → 同定義×同背景×同狀況 → 單獨一張表（可多表並列）
```

### 2.1 文本上：當下定義＝含金量 → 製成模塊

| 規則 | 說明 |
|---|---|
| **當下文本** | 以**目前正在處理的那份文本**為準，不拿別篇的尺度硬套 |
| **計量單位（優先序）** | ① 文本**明示**單位（如 token、概念頁、字數）；② 可穩定推出的單位；③ 回退：**Unicode 字元數**（含標點；空白規則見待裁 a） |
| **切塊粒度** | 對齊文本自訂契約（如「一概念一頁」、一資料夾職責、一可執行程序）；**不是**先定全域 N 字再切 |
| **字元的角色** | 主要服務 `char_span` 證據與「過大必切／過小不立」輔助；不得在文本已用 token／概念頁時，仍用字元冒充其成本語言 |
| **含金量數** | 依上述單位計得、或附在模塊上的 `gold_note`（如「8–15 頁」「省 70–90% token」）；**不是**股價或外部評分 |
| **製成模塊** | 達粒度且通過 CandidateDisposition 的段落 → 模塊候選；對齊領域「文本模塊」 |

**禁止**：

- 用與當下文本無關的固定全域字數覆蓋該文本自己的定義。
- 把含金量寫成投資／行情預測。
- 把星數、下載量、成長故事、訂閱安利當成含金量或立塊理由（`claim_kind=none` → discard）。

### 2.2 變成模塊後：依照原本規範紀錄

模塊候選要落成可引用的模塊時：

1. 依 [Library/CURRENT.md](../../Library/CURRENT.md) 指向的模塊層／證據等**現行規範**寫欄位與證據（`char_span` 等以規範為準）。
2. 走既有 Skill／站位習慣時，摘要標 **F2**（切模塊）；不新開作業模塊 ID。
3. 規範衝突 → **停止**並回報，不擅自改 canonical；試作產出只進試作紀錄。
4. 試作允許暫用 `LW-Cxx` 等前綴；**不得**寫進正式模塊庫。

### 2.3 後續：同定義×同背景×同狀況 → 單獨繪表

| 分組鍵 | 意義（草案） |
|---|---|
| **同定義** | 同一套含金量契約（單位＋粒度＋版本） |
| **同背景** | 同一文本背景、場景或來源脈絡 |
| **同狀況** | 同一使用／決策狀況 |

**預設狀況軸（可改，須在表頭寫明）**：

| 狀況值 | 典型放入 |
|---|---|
| 架構定義 | 問題、核心隱喻、結構元件、編譯規則 |
| 攝入編譯 | 解析／合併／連線／初始化／批次攝入 |
| 查詢維運與成本 | 查詢約束、日週維運、成本算術、權限 |

- 三者皆同 → 歸入**同一組**，為該組**單獨繪製一張表**。
- 任一鍵不同 → **另表**，不合併。
- **最小欄**（試作收斂建議）：候選 ID｜`char_span`／chars｜gold_note｜類型｜命題一句。

## 4. 試作怎麼跑

1. 選一篇當下文本，寫 **§2.1 契約表**（單位優先序＋切塊粒度）。
2. 先 CandidateDisposition 丟棄行銷／圖說／無命題段。
3. 依粒度切模塊候選 → 試寫規範向欄位（可無正式 ID）。
4. 依同定義／同背景／同狀況出 **≥1 張表**。
5. 記 [試作紀錄](../experiments/INDEX.md)；回饋改本稿，不自動升格。

首跑：[LLM Wiki 導覽文試作](../experiments/2026-08-05-d46-llm-wiki-spike.md)（19 候選模塊、3 張同分組表）。
