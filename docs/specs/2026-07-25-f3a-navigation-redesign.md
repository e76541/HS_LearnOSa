## 這次改掉了什麼

前一版叫「缺口驅動導航」，這次動的地方如下。

**「缺口」這個詞退休。** 它同時在講兩件處理方式完全相反的事，混在一起遲早出事。拆成兩個詞：文本裡沒有這塊，叫**空位**；文本裡有、但你自己搭不出來，叫**卡點**。

**站的組成改了。** 原本站是抽象的「子目的加上過站條件」，現在站由模塊團組成——照抵達判準挑出來的一堆模塊。

**步的單位改了。** 原本一步是一個模塊，現在一步是一題。模塊粗就多出幾題，一題一步。

**過站不再判通過或不通過。** 改成出一份檢討報告，你自己決定要不要往前走。

**多了一層分層。** 用來處理「這篇文本對這個人來說太高」這件事。

**明確劃出不做的事。** 選材、排課程路線不歸導航管。

## 整體架構

```text
文本
 │
 ├─ 技能樹        跨文本，記你會什麼，事件驅動
 ├─ 模塊與邊      這一篇的證據層，唯讀
 ├─ 分層          算出來的，不是存的
 └─ 導航          走一趟
```

**建的時候由上往下，跑的時候導航回頭餵技能樹。**

技能樹不是先填滿再開始用的東西，是越跑越厚。這件事要寫清楚，不然接手的人會把它當成前置工程，卡在那裡開不了工。

## 分層

分層回答一個問題：這塊模塊在你之上，還是在你這一層。

**分層是算出來的，不是存的。** 有人去標、去維護的話，模塊改了分層不會跟著改，兩邊一定對不上。做成隨時重算，跟決策牌那些投影一樣，要用再生。

**只用依賴那種邊來算。** 詳述、動機、解決那三種不代表誰先誰後，只有依賴才是「這個沒有，那個就不成立」。四種一起算會算出假的高度。

**先看技能樹，技能樹沒有才看文本。** 技能樹跨文本，文本只知道自己那篇，所以兩邊講不一樣的時候聽技能樹的。但剛開始技能樹是空的，前幾趟一定都走文本這條，這正常。

**分層是拿來篩，不是拿來排。** 它只圈出「你這層的模塊有哪些」，至於同一層裡面先走哪塊，還是你自己挑。這點要守住，不然「邊不決定順序」那條規則等於被繞過去了。

## 站

一個站就是一排**位**。位有三種：

**模塊位**——文本裡有這塊。你要自己搭一遍。計一步（卡住的話是搭、補、回來、再搭）。會擋過站。

**技能位**——文本裡沒有，但你技能樹上有。你要說出用哪個技能，而且要在組裝那關實際用上。計一步。會擋過站。

**空位**——文本裡沒有，技能樹上也沒有。沒事可做，掛著。不計步。**不擋過站。**

空位不擋過站的理由是結構性的，不是為了方便：**它沒有模塊，生不出題。** 考不了的東西不能拿來決定封不封站。

### 技能位的兩條規矩

**手動填進技能樹的技能不能拿來填空位。** 只有有事件撐的（對照層判過、九宮跑過的）才可以。這是技能樹本來就有的規矩——手動輸入只有否決權，不能主張。

**組裝那關沒用到就拿掉。** 不然「我會」就是免費通行證。

技能位填補之後**仍然計入空位額度**。不然一個站被技能填滿還顯示健康，煞車就失效了。而且它本來就在報告一件事：這篇文本沒教你這個。

### 站的硬規則

**零模塊的站不成立。** 整站都是空位的那個東西不是站，是願望。文本型至少要有一個模塊位。

**一站的空位超過模塊數一半，就是這站切錯了。** 處理順序是這樣，不准跳級：

```text
一站空位超過模塊數一半
      ↓
先重切這一站（把模塊重新分堆）
      ↓  還是一樣
重切模塊（切分本來就可以調，不受治理限制）
      ↓  還是一樣
這時候才是文本撐不起來，或終點訂太大
```

沒重切過就喊終點太大，砍掉的可能是自己拼壞的東西。

**重切救得了什麼要講清楚**：救得了模塊放錯站、沒認出某塊其實涵蓋了那個能力、位開太大。救不了的只有一件——原文真的沒寫。所以重切還有一個附帶功能：**空位重切一次還在，那它是真的。**

## 步

**一步等於一題，不等於一個模塊。**

模塊是證據的顆粒，題是走路的顆粒，兩者本來就不用一樣大。細的模塊出一題走一步，粗的模塊出三題走三步。

題是現生的，不是存的，所以要切多細都行，這是免費的。連帶一整類東西不用做：題庫、題目版本、出過哪題的紀錄，全部不存在。重考換一組題也是免費的。

### 模塊太粗的時候

先分清楚粗的原因是哪一種：

**這格其實塞了兩個命題簇** → 重切模塊。這是切錯，該修源頭。

**只有一個簇，但這個簇本來就厚** → 出多題。這時候硬分會違反命題簇規則。

判斷方法是問一句：這格能不能拆成兩塊，各自有自己的外部依賴？可以就分，拆了就殘就別分。合併同理——兩格永遠一起出現、單獨都站不住，那是一塊。

**分合是主修法，出多題是備案。** 出多題會把切錯的模塊蓋起來，走起來順了但它還是切錯的，下一趟還要再繞一次。重切是一次修好，所有人受益。

**但導航只出訊號，切分層動手。** 導航記「這格常卡」「這格總是跟隔壁一起卡」，把訊號丟出去；要不要分、怎麼分是切分層的事。這不是新加的限制，拆併回饋本來就是合法產物，導航自己動證據層才是禁的。

## 怎麼走一趟

### 兩個入口

**有底的人可以直接撞。** 進站之後不走格，直接考組裝。過了就封站，中間那些格一格都不用走。你們規格本來就寫過「過站但模塊未判會，能產出但知識不完整」屬於正常情況，這只是把它從「允許發生」變成「可以主動走」。

**全不會的人不要撞。** 撞出來全倒，那份報告是一張紅紙，沒有資訊。全不會是常態——打開一篇新文本本來就是不會才要讀。

### 全不會的時候，一格在做什麼

不是「重建」，你沒東西可重建。改成**先猜再看**：

```text
給你這格的舞台（這格在回答什麼問題）
      ↓
你猜一個（猜錯是預期的）
      ↓
看模塊
      ↓
接得上 → 下一格
接不上 → 記成「太遠」
```

猜錯不是失敗，是掛鉤。先自己想過一輪，看到答案才會卡進去；直接看就只是滑過去。

有底的人叫重建，沒底的人叫預測，留痕都有、對照都有，是同一套零件的兩個入口。

### 條是走出來的

開始的時候你只看到有幾格、各是什麼型，看不到內容：

```text
□模塊   □空位   □模塊   □技能   □模塊        剩五格
```

走一格填一格，填過的才顯示內容：

```text
■圖能標出並行步驟   ○空位（原文未寫）   ■每條邊要說得出為什麼   □技能   □模塊
```

**順序是你走出來的，不是先發給你的。** 先後關係本身就是答案，先給等於考卷跟答案一起發。撞過之後就無所謂了，那時候整條當提示看也可以。

也因為這樣，**團內沒有順序**，你自己挑下一格。

## 什麼叫舞台，什麼叫演員

出題的時候會給你背景，那不算洩題，只要給的是**題目**不是**答案**。

**可以給（舞台）**：這塊在原文哪個位置、要回答什麼問題、你前面已經自己搭好的東西。

**不能給（演員）**：主張、機制、成立條件、這塊跟誰有邊、什麼型的邊、例子與公式的內容。

一句話：**告訴你要打哪場仗，不告訴你怎麼打。**

另外，**背景模塊本身不算一步**。它是舞台，沒東西可重建，你沒辦法對一塊背景說「講出它的機制」。作法照素材那條走——跟著它服務的主模塊一起發下去。

## 過站：改成檢討報告

原本要「先寫過站條件，一定要在考之前」，是為了防事後照著做過的事回填、然後必然通過。

**但邊表在你開始之前就存在了，你回填不了。所以邊表本身就是先寫好的答案卷。**

保證從一個動作搬到一個資料結構上，誠實沒有掉。跟著可以刪掉的東西：過站條件這個欄位、幾條對算過的門檻值、撞幾次算放棄的上限、封站四步的時序。

剩下的流程是：

```text
撞一次 → 對邊表 → 出報告 → 你自己決定要不要往前
```

### 組裝那關考什麼

就一題，因為組裝本來就是一個整體：

> 把這站的模塊打散、無序攤開，你連起來，並說出每條線為什麼存在。

答案卷就是邊表，不用另外準備。

- 連對、理由對 → 記在報告上
- 漏連、連反方向 → 記在報告上（前提關係搞反代表結構沒懂）
- **連出邊表沒有的線 → 不算錯**，記成候選新邊，回饋給切分層

最後一條是重點，而且合法——回饋拆併訊號本來就是允許的產物，不算回寫證據層。

### 報告怎麼寫

**逐條，不准總評。** 「大致不錯，建議再複習」等於沒寫。要像這樣：

```text
這站：模塊四格、技能一格、空位一格

連對   三條
連反   一條   你說前面那個靠後面那個，實際是反過來
漏連   兩條
多連   一條   邊表沒有，記成候選新邊
空位   一個   原文沒寫，帶著走
太遠   零格
```

### 沒有東西擋你之後，唯一的煞車是報告要累積

結案的時候要有一份總帳：你帶著幾條沒補的、幾個空位走到終點。

不然就變成走過就算。而且這份總帳很有用，它就是一句話：**這篇文本教了你什麼、沒教你什麼、你自己補了什麼。**

## 程度落差怎麼處理

### 不評估程度

不問、不測、不分級。不因為某個人程度不夠就改模塊大小或站的大小——模塊是共用的證據層，把個人狀態寫進共用真值是模塊層第一條就禁的。

**對齊只發生在導航層。** 同一批模塊，強的人一格一步，弱的人一格三步，更弱的判太遠。模塊本身不動。

### 只記一個數

**「這格看完還是不懂」的次數。**

注意量的位置：**太遠要在看完模塊之後才算，不是看之前。** 看之前不會是常態，不是訊號。

- 看完接得上 → 正常學習，這就是主流程
- 看完還是接不上 → 太遠，前置不夠

**太遠超過一半就叫停。** 這時候不是叫他更努力，是**選錯文本或選錯終點**，該退出去補前置。

退出的時候他手上有一份清單：要讀這篇，你得先會這些。那份清單就是下一趟的終點。

### 卡點和太遠的處理是相反的

**卡點**是差一格，補一下、回原位、再搭就好。

**太遠**是差好幾層——再怎麼補一小塊都補不到，因為那塊的前提你也沒有，前提的前提你也沒有。這時候叫人繼續補是最糟的，會一直失敗。

正確處理是丟出去：跟空位走同一個出口，回填技能樹，這趟不解。

## 導航不負責的事

這一段是這次最重要的結論之一。

層級落差缺的不是零件，是**問題意識**。只知道好球壞球的人，缺的不是 OPS 的公式——公式給他也沒用，因為他腦裡沒有「怎麼比較兩個打者誰比較有貢獻」這個問題。**沒有問題，答案就掛不上去。**

零件可以一塊一塊補，問題意識不行。所以「差幾塊」跟「差一層」是兩種東西，不是同一種的大小差別。

**所以「這個人現在該讀什麼」不歸導航管。** 那是選材，跟導航平行，不是導航的功能。硬塞進來就會一直生出補丁，而且每個補丁長得都像最小一步——這正是裁決紀律要擋的東西。

導航該做的就三件：

- 撞到就認出來（這格看完還是不懂）
- 超過一半就叫停（不讓人硬走）
- 交出名詞清單（你卡在這些詞上）

**到此為止。不排路線、不找下一本、不負責填那一層。**

## 爬山：選下一篇的想法

這一段是選材層的雛形，**不屬於導航模式**，先記著。

先爬完一座矮的，下來，再爬下一座。真正有用的地方在於：**矮的那座會讓你開始想問一件事。**

讀完一篇入門的棒球文章，自然就會想「那到底誰打得比較好」。這個問題冒出來了，OPS 才有地方放。所以矮的那篇不是「先學基礎」，是**先讓你有問題**。

**「到頂」用現成的零件**：抵達判準就是山頂，不用新開東西。

**「下來」的意思是收工**：以後不用再翻那篇，你自己就講得出來。做不到就是還沒下來，只是人還站在上面。

**怎麼知道一篇會不會太高**：看它用了多少沒解釋的名詞。入門的什麼都會講一遍，高的直接假設你懂。這在切模塊的時候順手就有——哪些詞有人在講，哪些詞拿來就用。把那張名詞表跟你會的比一下，差太多就換一篇矮的。不用考人，也不用打分數。

**下一篇不一定要更高。** 旁邊那篇也可以，只要它假設的東西你剛好都有。硬要排成一條線反而會排錯——主軸只是啟發式、可被抵達判準推翻，是同一個教訓。

```text
│  ── 這一站的自檢 ──                     │
│  空位超過模塊一半 → 重切站 → 重切模塊     │
│  太遠超過一半 → 叫停，去補前置            │
│                                        │
└────────────────────────────────────────┘
      │
      ▼
所有站走完 → 結案，出總帳
（你帶著幾條沒補的、幾個空位、幾格太遠走到終點）
      │
      ▼
導航把事件回頭餵技能樹
（用過的技能加熟練度；用了但沒過的要扣或長盲區卡）
```

---

## 明確不做的事

- 不評估使用者程度，不測、不分級
- 不因為某個人改模塊大小或站的大小
- 不由導航動證據層，只出訊號給切分層
- 不排課程路線、不選下一本書
- 不把站樹做成模塊樹，不自動一個模塊一個站
- 不預先發整條路線（先後關係本身就是答案）
- 不維護題庫（題是現生的）
- 不用四種邊算高度，只用依賴
- 不把「太遠」當成使用者不努力
- 不在這一輪處理支線與延伸

## 還沒定的

**一站最多幾格。** 建議上限八格。理由是超過八步的站，原本的自檢規則就判太大了。

**模式名稱。** 現在叫「缺口驅動導航」，但缺口這個詞已經退休，驅動它的也換成模塊團了。名字跟事實對不上，要嘛改名，要嘛在開頭寫一句舊名保留的說明。

**舊指標怎麼收。** 缺口減少率、原地打轉警訊都是用舊的缺口在算。如果照原本的規劃把記帳類規則整批刪掉，這兩個本來就會消失，不用另外處理。

**技能樹要不要加「前置」這種邊。** 現在的樹是平的，只有「誰比較大」，沒有「誰要先」。要做到「你缺前置，去補這幾樣」需要前置關係。建議不要手寫，用旅程累積：有人在某格判太遠、後來把某個技能補起來回來過了，那就是一條前置邊的證據。但要誠實講：**第一趟給不出路徑，只給得出名詞清單。** 第一個人是開路的，他那趟就是下一個人的路徑。

**選材層要不要做、什麼時候做。** 爬山那一段只是雛形。至少可以確定它不在導航模式裡，也不該用最小一步去逼近它。
