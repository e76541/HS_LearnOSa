以 D48 為整體主幹，重新安排 `裁1～裁4` 的處理順序，只讓真正阻塞 WORK／LEARN 切換與返回的問題排在前面。

---

## 1. 主幹基準

```text
WORK：把事情做成
  ↓ 人的能力不足
LEARN：局部補能力 → 返回原 WORK 節點
  ↓ 需要正式結論
VERIFY：限制證據與結論權限 → 返回 WORK
```

裁案優先性依四問判斷：

1. 是否決定 WORK 要不要切進 LEARN？
2. 是否決定 LEARN 補完後能不能可靠返回 WORK？
3. 是否阻塞第一輪真實 `WORK→LEARN→WORK`？
4. 若只影響跨趟體感、熟練度統計或後續顯示，則後置。

VERIFY 由 D32～D34 獨立承接；裁1～4目前沒有一案直接阻塞 VERIFY。

## 2. 新優先順序與執行狀態

| 優先 | 裁案 | 新主幹角色 | 目前狀態 | 下一動作 |
|---|---|---|---|---|
| **P1** | **裁1** | WORK→LEARN 入口：外部缺口 vs 人的能力缺口 | **已重寫，待裁** | 使用者裁 A／B；未裁前只可作暫定試跑路由 |
| **P2** | **裁4** | LEARN→WORK：補到何種程度可返回原節點 | **待重寫** | 依 RBF1／D48 瘦身成返回協議，再裁 |
| **P3** | **裁2** | 跨趟「補過」狀態是否繼承 | **後置** | 真實重跑出現摩擦才處理 |
| **P4** | **裁3** | 引用／熟練度計點 | **移出主幹阻塞** | R／技能登記真的需要分數決策再處理 |

一句話：

> **先決定「什麼情況值得進 LEARN」，再決定「補到哪裡必須回 WORK」；狀態記憶與熟練度不能阻塞主循環。**

## 3. P1｜裁1：第一步重寫已完成

### 3.1 舊題已退出

舊題：

舊 A／B 依「能不能出題／文字有沒有出現」判斷，屬舊文本導航語境，不足以支撐 D48。

### 3.2 新題

裁1現已改為：

> **WORK 卡住時，什麼情況應留在 WORK 排錯／補資源，什麼情況才切入 LEARN？**

新版裁1的核心邊界：

```text
來源／輸入不存在                  → WORK
工具／API／權限／環境故障          → WORK
能力／服務供給根本不存在            → WORK
資源與工具可用，但人不會操作／理解／判斷 → LEARN
正式主張／採用結論的證據權限          → VERIFY
```

若一開始分不清，新裁1選項 A 主張「先做一次最小診斷，只取得足以路由的證據」；選項 B 則主張「只要不知道怎麼繼續就先進 LEARN」。Agent 建議 A，但尚未由使用者裁決。

### 3.3 已同步文件

- `docs/drafts/裁1.md`：已完成新題、A／B、風險、D38一致性檢查。
- D38：已明示 `L1-02` 只處理進入 LEARN 後的能力／策略卡點。
- 治理 INDEX：同步新標題與「已重寫、待裁」狀態。

### 3.4 邏輯檢查結果

新版裁1與 D48／D38 的邏輯目前一致：

1. **WORK 不會被 LEARN 吞掉**：工具故障、來源缺失仍由 WORK 處理。
2. **LEARN 不會變成資源搜尋垃圾桶**：只有「條件可用但人不會」才進 LEARN。
3. **L2 備料不足不等於來源不存在**：來源存在但尚未模塊化，可在 LEARN 中依 RBF1 觸發 SK-02／03。
4. **VERIFY 邊界保留**：證據能否支持正式結論，不由裁1或 LEARN取代。
5. **裁4接點清楚**：裁1只回答「進不進 LEARN」；裁4再回答「何時返回」。

因此，**第一步「重寫裁1＋邏輯／文件對齊」已完成；裁1本身仍是待裁，不可誤標已裁。**

## 4. P2｜裁4：下一步

舊裁4一次處理：材料、補完認定、失敗計數、場次紀錄。D48後真正阻塞主幹的只有：

> **LEARN 局部補足到什麼程度，才允許返回原 WORK 節點重試？**

預定重寫方向：

| 舊洞 | 新處置 |
|---|---|
| 材料是什麼 | 交 L3-02 按卡點組最小材料，不由裁4固定種類 |
| 補完怎麼認定 | **保留為裁4核心**：足以返回並重試原 WORK 節點 |
| 失敗計數 | 移出第一輪主幹；有 telemetry／叫停需求再處理 |
| 場次紀錄格式 | 降為附屬紀錄，不得阻塞返回 |

裁4完成後，第一輪主線才具有完整入口與出口：

```text
WORK
→ 裁1：是否進 LEARN
→ LEARN L1／L3
→ 裁4：是否足以返回
→ WORK 原節點重試
```
