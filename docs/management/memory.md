# 記憶（memory）

跨 session 的「不要／約束／已確認記住事項」。與「偏好」（怎麼協作）分開；本檔只記使用者確認過的邊界與禁項。

## 寫入規則

- Agent **不得擅自寫入**；須先詢問「是否列入記憶」，經確認後才追加。
- 觸發來源：使用者回覆中**短句式**提及的「不要／禁止／別再…」等；**不收錄**長文章、外部來源貼文或大段引用全文。
- 每條一行（可附日期）；刪改同樣須使用者確認。
- 與「偏好」衝突時，本檔的禁項優先。

## 現行條目

| 日期 | 條目 |
|---|---|
| 2026-07-22 | 不要廣告宣傳、個人故事、笑話等非主題內容 |
| 2026-07-22 | 不要對股價做預測 |
