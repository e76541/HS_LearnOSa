每個生效作業模塊在此有且僅有一節;已廢止作業模塊的節保留歷史、不再跑檢查、不得再以該 ID 記新列。
各節「必做檢查」條文視同規範內容:Agent 只能勾稽結果,增刪改條文須經使用者確認。
「擴充檢查」條文 Agent 可依規範第二節自動新增與計數 +1(`回歸:`/`驗證:` 前綴,附來源變更列編號);
合併、淘汰與計數歸零須經使用者確認。回歸檢查 ×2 時 Agent 必須提案升必做。
站位(F1～F4、T1～T3、R1、V1)與成品代號寫在摘要,不開獨立看板節。
