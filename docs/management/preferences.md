# 協作偏好

長期有效的使用者偏好。回答「以後請怎麼做？」。少改；明確說「記住」或拍板時才更新。

討論結論見 [decisions.md](decisions.md)。執行現況見 [roadmap.md](roadmap.md)。

## 溝通

- 全程繁體中文；簡潔、無鋪墊、無重複問題。
- 只在必要時提問；能從倉庫推得的資訊先自查。

## 管理文件

- **總覽**：導航與當下站位一句；不抄路線全文、不列完整 INI 表。
- **藍圖**：願景、目標樣貌、預期工程；不追「目前進度／阻塞」（那是路線）。
- **路線**：事項／裁決／阻塞的唯一執行真值。
- **交接紀錄**（`docs/management/current-handover.md`）：只放最新快照連結與一句話狀態。
- **交接快照**（`.agents/handover/`）：交接時建立，舊版不追改。
- 完成項：事項結案 → 路線「近期已結案」；樣貌 → 藍圖「已併入基線」；交接完成範圍 → 交接快照。

## 交付與提交

- 使用者說「交接」＝完成驗證、更新看板、建交接快照、更新交接紀錄；**不含** commit／push（自 2026-07-18 起）。
- 使用者說「推送」＝提交並推送指定變更；Git 操作全歸此指令。
- 明說「不提交」「只顯示」「擬作看看」時，只改工作區、不 commit／不 push。
- 除非明說「只產生臨時交接摘要」，不得用通用 handoff 臨時檔取代專案交接。

## Agent 讀取

接手或開始治理相關工作時讀本檔；與本次無關的偏好不需複述給使用者。
