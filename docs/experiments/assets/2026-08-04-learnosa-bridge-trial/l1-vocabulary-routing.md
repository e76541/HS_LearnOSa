# 驗證項目：詞彙分流表是否足以避免 Agent 混用

- 驗證等級：**L1 探路**
- 驗證狀態：**驗證完成**
- 問題領域：學習系統
- 驗證類型：概念分析
- 成果形式：表格（對接說明 §1）

## 探路問題

在不升格 canonical 的前提下，全專案詞彙分流表能否讓 Agent 區分「驗證等級 L1/L2/L3」與「深度三層／鷹架三級／管線驗證」？

## 本項完成條件

取得第一個可核對結果：對照表至少覆蓋 5 組高碰撞詞，且 AGENTS 有固定查表入口；或取得可核對阻礙說明不足。

## 【試】

用對接說明 §1 全專案詞彙分流表對照 AGENTS 既有「模塊／作業模塊」分流，要觀察 **Z**：Agent 是否能在不每次重對準的情況下選對系統前綴。

## 【見】

**可見結果**：

1. 對接說明 §1 列出 10 組三欄分流（驗證、L1/L2/L3、日誌、本次進展、模塊、卡、狀態、採用、評估）。
2. AGENTS 新增觸發詞「共同語言」「詞彙分流」，指向 glossary 與 bridge §1。
3. 試跑檢查清單逐項可勾；未出現需第三套混名的欄位。

**驗證物**：`docs/specs/2026-08-04-learnosa-hs-learnedge-bridge.md` §1、§2。

## 【判】

**另開後續項目**

理由：分流表足以支撐靜態查表；尚需第二道非管理類題目驗證「發布→F1→claim_kind」動態鏈。

## 發布

- 內容類型：驗證報告（試作附錄）
- 發布狀態：未發布（試作紀錄內）
