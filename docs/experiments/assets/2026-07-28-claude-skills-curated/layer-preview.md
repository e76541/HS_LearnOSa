## 1＝運用

- 解決「又一份爆紅 Claude skill 清單」：多數重排、連結錯、還可能裝到惡意腳本。
- 何時拿出來：要擴充 Agent skill、或被社群清單誘惑時，先用這篇的安全與上限紀律。
- 產出是「裝不裝／裝幾套／先讀什麼」，不是把十三套一次裝完。

## 2＝公式／判準

- 安全閘：裝前讀 `SKILL.md`（社群必讀；官方 anthropics 作者自述可較鬆）。
- 上限：少裝（作者建議約四套起），多了搶上下文、Agent 會抓錯 skill。
- 最小四件骨架：品味（Frontend Design）／文件準確（Context7）／流程（Superpowers）／自建（Skill Creator）；其餘情境再加。
