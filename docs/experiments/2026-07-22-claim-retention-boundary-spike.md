# 主張性質與純填充保留邊界紙上試切

日期：2026-07-22
性質：紙上試作，不含正式管線實作
相關作業模塊：M1（籌備）

## 目的

檢查長篇異質文本中，弱主觀主張是否能忠實保留而不冒充真值，以及問候、訂閱呼籲等純填充是否能在建立模塊前排除。

## 材料

1. 北宋末年人物與戰局敘事逐字稿：含背景、事件、作者推測、決策評論與節目收尾。
2. AI 工作流比較逐字稿：含可比較流程、作者建議、未驗證產品敘述與節目收尾。
3. 2026 占星解讀逐字稿：含可查核天象敘述、二手轉述、詮釋、預測、生活建議與訂閱呼籲。

材料僅作紙上邊界測試；未正式收錄，未配發 text ID 或 module ID。

## 觀察

- 四種既有模塊本體足以承載保留內容，但「忠實抽取」不等於「主張已證實」。
- `AnalysisModule` 需要在既有 `claim／evidence／assumptions／counterarguments` 中維持說話者、來源層級與支持缺口。
- 行動建議若缺約束，現行弱策略點規則可攔截過度泛化。
- 問候、訂閱、留言邀請、重複總結等片段不支撐技能命題，也不構成必要背景；若先配發 `module_id` 再排除，會造成假模塊與數量膨脹。
- 背景與純填充不可合併處理：背景仍可能支撐技能模塊，純填充則不應建立模塊。

## 試切結論

採模塊建立前候選分流：

```text
主張性質 → 背景必要性 → retention → 模塊分型
```

- 主張性質：`verifiable_claim／attributed_claim／interpretation／prediction／advice／none`。
- 來源層級：`primary／secondary／unknown`。
- 支持狀態：`provided／missing／unverified`。
- 保留結果：`retain／discard／needs_review`。

`discard` 不配發 `module_id`、不留下獨立摘要、節點、邊或對齊項；原文仍由來源完整保存。這能使占星樣本中的頻道介紹、按讚訂閱與留言邀請不形成先前試切的 M08 類假模塊。

## 待基準驗證

- 主張性質的人際標註一致性。
- 背景誤刪率與純填充誤留率。
- `needs_review` 比例是否過高。
- 不同文章類型是否需要補充邊界例；未經數據不得新增第七類。
