# 更新說明

## 定義

修改生效規範或 `AGENTS.md` 規則內容、或必做檢查條文前，Agent 在對話中先輸出的**確認用說明**；使用者確認後才准落檔。

## 固定四格

1. 改了什麼（白話，以前→現在）
2. 使用者要做的事
3. 使用者不用記的事
4. 落點（將修改的文件）

## 準用

- 節名與正文一律寫「更新說明」。
- 升級流程對應物稱「升級更新說明」。
- 大幅更新的完整檔另存 `.agents/handover/reference/update-notes/YYYY-MM-DD.md`。

## 禁用

- 不得簡稱「卡」「出卡」「留卡」「完整卡」等（見規範第七節）。
- 舊稱「更新卡」僅容忍歷史檔；新寫禁止。
