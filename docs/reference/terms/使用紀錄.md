# 使用紀錄

## 定義

使用優先學習迴路中，文本進入主迴路時的**最低產物**（五欄：規則／情境／計畫／結果／下一步等，以現行草案為準）。本身**不是**驗證項目，也沒有驗證等級。

## 準用

- 正文、檔名、對話一律寫「使用紀錄」。
- 檔名建議：`usage-record.md`。
- 可標 `角色：主／副` 等狀態標記（狀態非五欄產物）。

## 禁用

- 不得稱「使用卡」「缺卡」「進卡」「收卡」。
- 不得把使用紀錄當成驗證項目或 L1／L2／L3。
