# 草案短代號

## 短定義

每一份**草案**必須有一個短代號，供口頭與交叉引用；不得只靠長檔名。

## 格式（兩系，不混用）

| 系 | 格式 | 管轄 | 真相表 |
|---|---|---|---|
| 領域草案 | `D{n}`（正整數，不補零） | `docs/specs/`、`docs/plans/` | [docs/INDEX.md](../../INDEX.md) |
| 治理待裁 | `裁{n}` | `docs/drafts/` | [docs/drafts/INDEX.md](../../drafts/INDEX.md) |

## 準用

- 新開領域草案：同次在 INDEX 登記並取下一個未用 `D{n}`；檔頭必有「短代號」列。
- 新開治理待裁：依既有裁號規則取 `裁{n}`（裁號即短代號）。
- 回覆／看板／交接提到草案時，優先帶短代號（可附標題）。
- 號一經使用不改義、不回收給不同檔。

## 禁用

- 不得用作業模塊 ID、站位、成品 `C{n}`、`INI-*`／`ADJ-*` 充當草案短代號。
- 不得把 `D{n}` 與 `裁{n}` 混指同一檔。
- 不得自創第三系前綴（如 `草{n}`）除非先經更新說明改本定義。
