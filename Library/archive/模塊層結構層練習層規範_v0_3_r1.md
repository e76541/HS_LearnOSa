# 模塊層・結構層・練習層・登記層規範 v0.3 r1

**狀態**:草案(2026-07-12 架構整併版;r1 補背景屬性與排版整理)
**取代**:v0.2 r2(含 2026-07-12 討論全部結論)
**版本裁決註記**:凍結條款原定 v0.3 以 30 篇基準數據開啟。本次由 AOI 裁決提前開版,語義為「架構完備版」而非「數據驗證版」;所有依 P6 掛起之項目維持掛起,數據到位前不轉正。
**證據基礎**:SRC-001(機器學習基礎教學文,人工垂直切片)+ SRC-002(迴圈工程文,現場實跑)
**適用範圍**:資訊分流管線中「模塊化 → 編碼 → 結構化 → 練習生成 → 技能登記」五段。不涵蓋文件正規化、熟練度模型本體(登記層僅為其儲存介面,見 §6.3)。
**行文約定**:正文以中文行文;英文識別符僅於首次定義、schema 代碼塊與附錄 C 對照表出現。儲存層一律英文、閱讀層一律中文,依附錄 C 定位聲明。

## 第一章 設計原則

**P1 模塊是索引面,不是閱讀面。**
模塊層是原文的有損索引。任何下游需要原味內容(尤其練習素材)必須經字元區間回原文取材,禁止只消費模塊摘要。

**P1a(v0.3 推廣)銜接文字溯源至邊。**
渲染物(講稿、投影片)中的正文段落溯源至字元區間;銜接語句溯源至邊。每個字都有出處,出處分兩軌。

**P2 耗損是功能,但必須分層量測。**
實測基線(SRC-001,約 65 條原子命題):概念約九成五、機制鏈約九成、量化細節約五成、類比與記憶鉤約一成五、敘事順序約三成。籠統的總保留率無意義,驗收一律分層報告。

**P3 缺的資訊用邊補,不用更細的節點補。**
敘事與關係層的耗損由有類型的邊挽回,增量成本約為模塊化的一成五。禁止以縮小節點粒度(心智圖式短標籤)換取結構——那會摧毀機制鏈的高保留率。

**P4 空欄位必須有語義。**
欄位為空只允許表達「作者未提供」;「此型別不適用」必須由分型消除,不得由空值承擔。

**P5 匹配引擎只讀核心投影。**
技能對齊永遠面對同一種語言(模塊核心投影);型別分化不得污染對齊層。

**P5a(v0.3 推廣)層間邊禁止互通。**
模塊層的邊描述論證結構,真值來自文本;登記層的邊描述分類關係,真值來自領域共識。語義域不同,永不跨層混用。

**P6 證據先於規格。**
任何新型別、新邊類型、新圖式、新狀態轉移規則,須以基準標註數據為前提。無數據不開規格。

**P7(v0.3 新增)單向閥:圖生成投影,投影永不回流。**
講稿、投影片、心智圖皆為圖之投影(動態視圖),反向重建不成立,禁止回灌模塊化管線。使用者口述逐字稿屬量測記錄,同樣不進圖。

**P8(v0.3 新增)封閉世界:練習問題空間等於圖的組合。**
問題僅得取材於「節點欄位 × 邊 × 圖式實例 × 跨來源候選邊」。圖外實體不得入題;圖外證據僅得入答,且經回填轉化為圖的生長。

## 第二章 模塊層

### 2.1 分層綱要

```text
ModuleCore(凍結;改動 = breaking change)
├─ module_id / source_id / char_span
├─ article_type / semantic_roles
├─ domain / operations / problem_type
├─ input_type / output_type
├─ cognitive_level / is_skill_signal
└─ confidence / schema_version / extractor

型別本體(隨型別入凍結集時一次性定義)
├─ TeachingModule : concept_core, examples, hooks, limitation
├─ MethodModule   : procedure, constraints(必填,允許值「作者未給」),
│                   preconditions, failure_modes
├─ CaseModule     : context, actions(含事件序), outcome, transferability
└─ AnalysisModule : claim, evidence, assumptions, counterarguments
```

- 匹配引擎僅准讀核心投影(P5);資產提升與練習生成方可讀型別本體。
- 模塊為唯讀證據層:生成後不變,不承載任何流轉狀態。狀態一律住登記層(第六章)。

### 2.1a 素材標註

記憶鉤欄位為帶型別的素材項清單,每項攜帶字元區間回指原文,附屬宿主模塊,不獨立成節點:

```text
hooks: [ { kind: story | quote | formula, char_span, note? } ]
```

- **附屬不脫勾**:模塊拆分時素材隨其字元區間歸屬的子模塊搬遷。
- **不進邊層、不進對齊**:結構層畫模塊間關係時不讀素材;素材對邊層與對齊層皆不可見。
- 公式類素材維持雙記過渡(候選 C5 未結)。
- **實測補充(SRC-002)**:方法型模塊的素材幾乎全為公式類,敘事鉤(故事、金句)集中於教學與案例型模塊——演講素材因此常需跨出鏈外取用,此即背景模塊條款(2.6)與放寬規則的實證動機。

### 2.2 拆分規則

一個模塊可有多個語義角色,但其主要命題必須屬於同一命題簇。**不同簇之命題各有不同外部依賴目標,強制拆分。**簇歸屬或依賴目標無法確定時,標記「待人工覆核」,不自動切分。

同簇判準(至少符合一項):一者詳述另一者;一者例示另一者;兩者共同構成不可分割的機制;移除任一者使另一者語義不完整。不因主題相同而自動合併。

### 2.3 弱策略點規則

方法模塊的約束條件值為「作者未給」時,構成弱策略點:

1. 禁止生成應用型練習(無邊界條件的規則練習訓練過度泛化)。
2. 替代路徑:降轉未知項進問題模型,待第二來源補條件後升級;或生成「邊界獵取」型評估題(此規則何時失效)。
3. 弱策略點為演講問答之優先選題靶點(4.2a 第三幕)。

### 2.4 非技能訊號(r1 拆為兩檔)

技能訊號為否的模塊,依語義角色再分兩檔:

| 技能訊號 | 角色含「背景」 | 身份 | 待遇 |
|---|---|---|---|
| 是 | — | 正常模塊 | 全流程 |
| 否 | 有 | **背景模塊** | 依 2.6 |
| 否 | 無 | 純填充(行銷、鋪陳) | 僅保留字元區間連續性,不進任何下游 |

### 2.5 零散來源(條件式生效)

**定義**:跑完模塊化與邊抽取後,有效模塊數至少一、但內部邊數為零之來源。

**規則**:零散來源僅得掛靠(attach-only)——僅於對齊命中既有登記節點且過人工覆核時完成收錄;未命中者不建模塊,原文退回候選池,待登記簿長出對應節點後再撿回。不自含之片段(依賴外部語境、命題單獨不成立)於管線入口即擋。

**生效條件**:對齊操作可用(6.3)。登記簿空置或極小時本條自動休眠。

**入口三問(規範外操作備註)**:任何存量文字進管線前——一問,有原文未主張之主張否?無則棄。二問,主張獨立成立否?是則為來源,走正常管線。三問,有具體斷邊題現在要用它否?有則作一次性作答素材,答案回填成邊後即棄。三問出口無「以零散身份儲存」一項;「零散」不是系統持有的類別。

### 2.6 背景模塊(r1 新增)

**動機**:量多、不主要、但缺了就難談論的內容——鋪陳、業界脈絡、人物軼事。實證:SRC-002 的 M14(作者三年軌跡)為技能訊號否,卻是演講稿的最佳開場鉤。二值制無法區分「行銷垃圾」與「撐場面的背景」。

**標記方式**:不動模塊核心欄位(避免破壞性變更)。於語義角色清單增列值「背景」(background);技能訊號維持否。

**判準(給抽取器)**:命題對至少一個技能訊號模塊構成動機、伏筆或情境支撐,但自身無程序、無可遷移主張者,標背景;連支撐都不構成者,為純填充。

**消費規則四條**:

1. **不進對齊**:背景模塊不進對齊操作,故不產生亦不影響任何登記層狀態(含熟練度);其素材使用不計入語義評分。
2. **渲染層可讀**:講稿與投影片生成時,允許取用與鏈端點有邊相連之背景模塊的正文與素材。4.2a 原「放寬條款」由此轉正——開場鉤的家本來就是背景模塊。
3. **可當邊的端點,不可當圖式主體**:背景常為動機邊與伏筆邊的來源,禁其上邊會丟失真實結構;但不得入鏈、不得當星形樞紐、不得被拔點——圖式抽樣時背景節點視同不存在。
4. **問答中只作題幹語境,不作考點**:「作者用某軼事鋪陳了什麼主張」合法(考點是被鋪陳的主張);「該軼事的細節為何」不合法(考背景本身,無技能價值)。

**一句話定位**:背景是舞台,不是演員——渲染時要它,計分時無它。

## 第三章 結構層(邊)

### 3.1 邊詞彙(核心加型別擴充)

```text
核心(全型別):depends_on / exemplifies / elaborates /
              equivalent_to / contrasts / motivates / solves
型別擴充:
  教學・敘事型:foreshadows
  方法型(預留):condition(自 RST 引入,待基準數據)
  案例型(預留):事件因果邊(待 30 篇中案例型實測後裁決)
```

- 等價邊無方向;其餘依 3.2。
- 伏筆邊為唯一無標準標註傳統者,抽取穩定性須單獨驗證。
- 擴充詞彙前先查修辭結構理論關係清單及其標註一致性數據;人類標不穩定的關係,模型產出即雜訊,不得引入。

### 3.2 方向規約

箭頭指向被支撐者(子指向父、後指向前)。例:M09 —解決→ M08;M03 —例示→ M02。

### 3.3 維度覆蓋(邏輯・因果・時序)

| 維度 | 載體 | 說明 |
|---|---|---|
| 功能因果 | 邊:解決、動機、依賴 | 模塊間粗粒度因果 |
| 細粒度推理鏈 | 模塊內機制角色 | 不上邊層,防圖爆炸 |
| 邏輯等價、實例、對立 | 邊:等價、例示、對比 | — |
| 蘊涵與條件 | 暫缺;方法型預期需要 | 屆時引入條件邊 |
| 文本順序 | 字元區間線性層 | **禁設順序邊**(資訊重複且誘發全連接濫標) |
| 敘事時間 | 邊:伏筆 | 線性順序推不出的鋪陳與回收 |
| 事件時序(案例) | 暫由案例角色集隱含 | 升格與否待實測 |

### 3.4 抽取程序:兩遍式

1. 第一遍,局部逐對判斷。候選對:相鄰模塊、序號距離不超過局部窗口(初值二,待基準校準,調整不構成破壞性變更)、同一小節內全部模塊。全局結構(脊柱、樞紐)為湧現結果,不做全局設計。
2. 第二遍,全模塊摘要一次全局掃描,專抓長程邊——即不符合第一遍候選條件的模塊對(伏筆、遠距等價)。實測佔比約十二分之一,成本可控。

### 3.5 無章節降級鏈

章節樹,缺席則段落序列,保底則字元區間線性順序。章節帶是排版鷹架,非承重結構;任何輸入下「模塊可回原文」驗收恆成立。結構越差的來源,邊層挽回率越高。

### 3.6 免費副產品(准用,不另建機制)

- 入邊數為重要性之**代理指標**(樞紐訊號,供資產優先序排序)。**禁止僅以入邊數自動決定資產提升;提升一律過人工關卡**——錯誤節點、通用背景節點(2.6 之防範對象,本條為既設防線)、切分過粗節點皆可能高入邊。
- 邊層反向偵測拆分(2.2)。
- 圖結構參數(鏈長、星形入邊數、拔點深度)即練習難度刻度。

### 3.7 心智圖定位

本結構為概念圖(節點加有標籤有向邊)。心智圖是其有損投影,僅作動態視圖;反向重建不成立,故儲存格式必須是圖。(v0.3 起與講稿、投影片同受 P7 統轄。)

### 3.8 邊的生命週期(v0.3 新增,最小版)

- 邊得標記**失效**(stale)——斷邊題或跨來源新證據與既有邊矛盾時,舊邊不刪除(保留證據鏈),標失效並記觸發來源。
- 失效邊不參與圖式抽樣與練習生成。
- 完整邊狀態機列 v0.4 候選 C7,依 P6 掛起。

## 第四章 練習層

### 4.1 單模塊題:角色對照題型

| 語義角色或本體欄位 | 題型 |
|---|---|
| 概念核心 | 回憶、解釋 |
| 機制 | 解釋、診斷 |
| 失效模式 | 診斷 |
| 決策規則(有約束條件) | 應用 |
| 決策規則(約束為「作者未給」) | 評估(邊界獵取,依 2.3) |
| 案例(情境、行動、結果) | 遷移 |
| 主張加證據 | 評估 |

凡含至少一個有效技能訊號模塊之文章,練習產能不為零。全數為否者允許產能為零並記原因碼「無技能訊號」。

**去重降級(v0.3 新增)**:模塊對齊命中熟練度為「已掌握」之節點時,單模塊題不生成,僅保留跨來源題型(斷邊)與約束條件補強檢查;模塊層建置照常,字元區間完整性不受豁免。已知內容的閱讀價值自「學習」切換為「校對」。

**下位新節點條款**:命中已掌握節點之下位新節點(上下位邊可判——如已掌握夏普比率,新來索提諾比率),不算重複;生成與已掌握兄弟節點之對比題,起點非零。

### 4.2 跨模塊題:圖式文法

隨機性僅用於抽圖式與抽子圖實例,**禁止隨機走圖**(P8 統轄)。

| 圖式 | 圖形 | 題型 | 組合約束 |
|---|---|---|---|
| 鏈 | 甲→乙→丙同型別邊串接 | 因果推理(補全、重排、必經步驟) | 鏈段限依賴、動機、解決之一,且全鏈同型別;混型鏈暫禁(候選 C2);例示邊不得居中;背景模塊不得入鏈(2.6) |
| 星 | 樞紐加至少三條入邊 | 抽象化(多例歸一) | 入邊須來自不同領域或角色;背景不得當樞紐 |
| 反事實 | 刪一節點 | 結構理解(下游塌什麼) | 被刪節點須有至少一條入射依賴邊;背景不得被拔 |
| 斷邊 | 跨來源同技能模塊對 | 遷移(同構或矛盾) | 兩來源須對齊同一登記節點 |

### 4.2a 演講場次(v0.3 自演講題擴充;狀態:C4 試跑條款)

一次場次等於一條合規鏈,四幕:**備、講、問、記**。

**第一幕・備(投影片生成)**

- 一頁等於一模塊,換頁等於一條邊;頁面正文硬上限為節點人話標題加素材錨一行,其餘一律住備忘稿層。
- 顯示規則:頁面與題卡顯示模塊主命題短標題(中文人話),模塊編號僅角落溯源。
- 素材取用:強制取用鏈上素材;並依 2.6 消費規則二,允許取用與鏈端點有邊相連之背景模塊素材(開場鉤條款)。試跑期間記錄背景素材使用率。
- 生成守 P1 與 P1a:正文回字元區間,銜接回邊。

**鷹架三級(收斂於備忘稿層;頁面三級無差,觀眾視角恆為第三級密度)**

| 等級 | 備忘稿內容 | 訓練目標 |
|---|---|---|
| 第一級 | 全文講稿,照念 | 表達與素材熟悉(冷啟動) |
| 第二級 | 每節點一句話提示,加銜接任務標記(邊的口頭作業) | 局部重建;翻頁瞬間強制講出依賴關係 |
| 第三級 | 空白 | 完整重建 |

- 第二級顆粒規則(試跑假說):節點給標題、邊留白。成立則可自動生成。
- 鷹架起點由熟練度決定:鏈上節點多數已掌握,則自第二級起跳,且講題升級為雙來源版(自有系統對照,依 4.3 進階形式)。

**第二幕・講(錄音)**

- 翻頁時間戳即模塊邊界基準真值(停頓位置判別假說之免費標記)。
- 評分僅算語義三維:鏈節點覆蓋率、敘事中邊方向正確性(講反因果扣分)、鏈上素材使用數。背景素材使用另記一欄(表達力觀測值),不入語義三維。難度沿 3.6 圖結構參數。

**第三幕・問(會後提問形式)**

問題空間依 P8 封閉,合法問型四種:

1. **單節點問**(本體欄位)——評分沿 4.1。
2. **單邊問**(存在性、方向、類型)。
3. **子圖問**(圖式實例:鏈補全、星歸納、拔點塌陷)——評分沿 4.2。
4. **跨來源候選邊問**(斷邊形態)——答案回填,依 4.3。

規則:

- 每問攜帶溯源(模塊編號、邊編號或圖式實例);無溯源之問不得出。
- 追問合法性為定義域檢查(仍須落於四型),不設層數封頂。
- 背景模塊依 2.6 消費規則四:只作題幹語境,不作考點。
- 問題池可窮舉:封閉世界下單鏈合法問題總量可數,預生成全池、標溯源與難度,現場按選題規則抽取(自動化列候選 C10)。
- 選題優先序:演講中邊方向含糊處(依語音轉寫比對,可靠性待驗)、弱策略點(2.3)、已掌握節點之斷邊問(往自有系統打)。第一項驗證不過則退回後兩項。

**第四幕・記**

- 演講量測訊號(時長、停頓位置與時長、語速、填充詞率、詞級時間戳逐字稿)一律**只收不評**,存為觀測欄位;第一級錄音不計入任何熟悉度訊號(防背稿)。
- 問答評分照既有題型邏輯;兩軌不混。
- 斷邊答案回填新邊;與既有邊矛盾者觸發失效標記(3.8)。
- 介面聲明:練習層產出之口頭量測訊號僅供熟練度模型層消費,不進本規範評分。

**狀態**:C4 試跑條款,自動化產線之外。試跑二至三篇驗證:素材抽取穩定性、背景素材使用率、第二級顆粒規則、語音比對選題可靠性、流暢度訊號與語義分之同向性。

### 4.3 回填原則

斷邊題作答產出新邊(等價或對比):練習回填圖,不只消耗圖。進階形式:以使用者自有專案為第二來源(調度型、無標準答案)。使用者既有文稿得作為斷邊題之一次性作答素材(依 2.5 入口三問),不設獨立收錄類別。

### 4.4 承重聲明

邊層為練習層承重結構。邊的錯誤下游放大,故邊之驗收嚴於模塊:**寧缺勿錯**。

## 第五章 驗收與度量

**5.1 基準標註範圍**:三十篇每篇標註——文章類型、模塊邊界、語義角色(含背景標記,r1 增)、型別本體必填欄位、邊基準真值、應產資產、應對齊技能、素材項。**v0.3 增列**:每篇記錄對齊命中數(對前序已標節點),累積繪製重疊率曲線,作為登記簿回本點之實測依據。

**5.2 耗損指標**:每篇列原子命題清單,檢查「命題可自模塊層恢復」比例,分五層(概念、機制、量化、類比、敘事)報告,作為不同抽取器的比較基準。

**5.5 學習效果對照(v0.3 新增,最小版)**:系統終極主張「管線化練習優於自然重讀」目前零證據。最小對照:同難度兩篇,一篇全管線、一篇自然閱讀,兩週後同套問答評分對比。不隆重、不阻塞,三十篇期間至少執行一組。輸贏都要知道。

## 第六章 技能登記層(v0.3 新增)

### 6.1 定位

**不是樹,是登記簿加一種邊。**平面節點清單,節點間允許唯一一種關係「上位於」(broader_than)——即詞表模式(SKOS):正名、別名集、上下位邊三件套。不強制全連通、允許多父、孤節點合法。樹形結構若需要,自人工覆核積累中湧現,禁止先驗設計。

**與模塊層同構、不同物。**同一套圖基建(節點表、邊表、儲存、渲染,含知識村莊視覺層),但——

| | 模塊層 | 登記層 |
|---|---|---|
| 節點錨定 | 文本(字元區間) | 抽象(跨來源匯聚點) |
| 生命週期 | 唯讀證據 | 可寫狀態 |
| 邊的語義 | 論證結構(真值自文本) | 分類關係(真值自領域共識) |

兩層以對齊操作縫合;一個登記節點即「跨來源被判定為同一技能之模塊等價類」。層間邊禁互通(P5a)。

### 6.2 節點綱要(最小)

```text
SkillNode
├─ node_id
├─ preferred_label(英文 canonical)+ display_name(中文)
├─ aliases: []          ← 每次命中吸收新說法;粗篩準度來源
├─ proficiency: new | learning | mastered(顯示:新/學習中/已掌握)
├─ proficiency_updated_at
└─ evidence_refs: []    ← 指向場次與評分記錄
```

**分界原則:登記簿存狀態,不存證據。**證據如何換算成狀態(幾分算掌握、多久不碰降級)屬熟練度模型層,在本規範範圍外。

### 6.3 對規範暴露之四操作(介面凍結)

本規範各條款僅依賴此四者;登記層內部規則另立。

1. **對齊 align(模塊) → 命中節點、前五候選、或拒絕**
   實作:向量粗篩(全簿掃描,節點描述加別名集)→ 模型細判三選一(同一、子項或近親、都不是)。「子項或近親」產出候選上下位邊,過人工。**觸發降級之命中一律過人工覆核**——錯誤命中的代價(以為會了)高於重複學習。背景模塊不進本操作(2.6)。
2. **待建 pending(模塊) → 待建新技能槽**
   拒絕之累積處。同向訊號升格閾值屬登記層內部規則,待裁決(R10)。
3. **節點識別 node_id → 穩定識別符**
4. **熟練度 proficiency(節點) → 新、學習中、已掌握;讀寫皆經此操作**
   狀態轉移規則屬熟練度模型層,依 P6 待試跑數據。**v0.3 過渡:狀態由人工設定(AOI 手標),系統只讀不寫**;系統同步收集量測訊號,三十篇後以手標為基準真值做相關性分析,再議寫入權移交。衰減路徑列候選 C9。
