### 7.1 文檔儲存流向(v0.3 r2 新增)

| 處理結果 | 儲存位置 | 索引待遇 |
|---|---|---|
| 尚未完成必要處理 | `Inbox/` | 不進 `DOC/INDEX.md` |
| 已完成且屬主要收錄類型 | `DOC/Stocks/` | 必須登記 |
| 已完成且屬非主要收錄類型 | `DOC/Archive/` | 必須登記 |
| 已完成處理,但類型或品質待人工覆核 | `DOC/Review/` | 必須登記並填 `review_reason` |
| 入口三問淘汰 | 不保存 | 不登記 |
| 一次性素材已回填為邊 | 原文棄置 | 不登記原文 |

`DOC/INDEX.md` 為人工可讀的查找入口,不是證據層、登記層或流轉狀態的真值來源。索引至少記錄 `text_id`、`title`、`bucket`、`status`、`path`、`review_reason`;未裁決 ID 可用 `PENDING-*` 暫時鍵。每個文檔以資料夾為移動單位,索引路徑指向其 `README.md`;移動與索引更新須同次完成,不得跨 bucket 重複。

`DOC/Archive/` 保存已完成但非主要收錄類型的文檔,與 `Library/archive/` 的唯讀規範快照語義不同,不可混用。待覆核項完成裁決後移至 `DOC/Stocks/` 或 `DOC/Archive/`;未完成項仍留 `Inbox/`。

## 附錄C 標籤中英對照表

**定位聲明:英文為 canonical 識別符,用於綱要、提示詞與儲存(欄位名、鍵值、邊類型值);中文僅供閱讀與介面顯示,不得作為儲存值。顯示層查本表,儲存層不動。中文名如與正文語義衝突,以英文定義為準。**

### C.1 邊類型

| 英文 | 中文 | 語義備註 |
|---|---|---|
| depends_on | 依賴於 | 子指向父,乙的成立依賴甲 |
| exemplifies | 例示 | 實例指向概念;固定譯例示,與詳述拉開距離 |
| elaborates | 詳述 | 對某模塊更細展開 |
| equivalent_to | 等價於 | 無方向 |
| contrasts | 對比 | 互為對照或矛盾 |
| motivates | 動機於 | 乙動機於甲,讀作乙的動機來自甲 |
| solves | 解決 | 乙解決甲,乙解決甲提出的問題 |
| foreshadows | 伏筆 | 教學敘事型擴充;鋪陳指向回收 |
| condition | 條件 | 方法型預留,待基準數據 |
| broader_than | 上位於 | **登記層專用**(6.1),與以上模塊層邊永不混用(P5a) |

### C.2a 模塊建立前候選分流(r6)

下列識別符屬模塊建立前的抽取／稽核資料,不屬於 ModuleCore,不得被匹配引擎當作模塊欄位:

| 英文 | 中文／邊界 |
|---|---|
| CandidateDisposition | 候選分流 |
| claim_kind | 主張性質 |
| verifiable_claim | 可外部查核的主張;不等於已驗證 |
| attributed_claim | 有明確說話者／來源的轉述主張 |
| interpretation | 作者詮釋 |
| prediction | 未來預測 |
| advice | 行動建議 |
| none | 無獨立主張 |
| provenance(primary / secondary / unknown) | 來源層級(一手／二手／未知) |
| support_status(provided / missing / unverified) | 支持狀態(有提供／缺失／未核對) |
| retention(retain / discard / needs_review) | 保留結果(保留／丟棄／待人工覆核) |

`retention` 不譯為「啟用」:啟用是作業模塊專用術語。`discard` 候選不配發 `module_id`,因此不是「停用模塊」。
