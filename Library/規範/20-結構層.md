## 第三章 結構層(邊)

### 3.1 邊詞彙(核心加型別擴充)

```text
核心(全型別):depends_on / exemplifies / elaborates /
              equivalent_to / contrasts / motivates / solves
型別擴充:
  教學・敘事型:foreshadows
  方法型(預留):condition(自 RST 引入,待基準數據)
  案例型(預留):事件因果邊(待 30 篇中案例型實測後裁決)
```

- 等價邊無方向;其餘依 3.2。
- 伏筆邊為唯一無標準標註傳統者,抽取穩定性須單獨驗證。
- 擴充詞彙前先查修辭結構理論關係清單及其標註一致性數據;人類標不穩定的關係,模型產出即雜訊,不得引入。

### 3.2 方向規約

箭頭指向被支撐者(子指向父、後指向前)。例:M09 —解決→ M08;M03 —例示→ M02。

### 3.3 維度覆蓋(邏輯・因果・時序)

| 維度 | 載體 | 說明 |
|---|---|---|
| 功能因果 | 邊:解決、動機、依賴 | 模塊間粗粒度因果 |
| 細粒度推理鏈 | 模塊內機制角色 | 不上邊層,防圖爆炸 |
| 邏輯等價、實例、對立 | 邊:等價、例示、對比 | — |
| 蘊涵與條件 | 暫缺;方法型預期需要 | 屆時引入條件邊 |
| 文本順序 | 字元區間線性層 | **禁設順序邊**(資訊重複且誘發全連接濫標) |
| 敘事時間 | 邊:伏筆 | 線性順序推不出的鋪陳與回收 |
| 事件時序(案例) | 暫由案例角色集隱含 | 升格與否待實測 |

### 3.4 抽取程序:兩遍式

1. 第一遍,局部逐對判斷。候選對:相鄰模塊、序號距離不超過局部窗口(初值二,待基準校準,調整不構成破壞性變更)、同一小節內全部模塊。全局結構(脊柱、樞紐)為湧現結果,不做全局設計。
2. 第二遍,全模塊摘要一次全局掃描,專抓長程邊——即不符合第一遍候選條件的模塊對(伏筆、遠距等價)。實測佔比約十二分之一,成本可控。

### 3.5 無章節降級鏈

章節樹,缺席則段落序列,保底則字元區間線性順序。章節帶是排版鷹架,非承重結構;任何輸入下「模塊可回原文」驗收恆成立。結構越差的來源,邊層挽回率越高。

### 3.6 免費副產品(准用,不另建機制)

- 入邊數為重要性之**代理指標**(樞紐訊號,供資產優先序排序)。**禁止僅以入邊數自動決定資產提升;提升一律過人工關卡**——錯誤節點、通用背景節點(2.6 之防範對象,本條為既設防線)、切分過粗節點皆可能高入邊。
- 邊層反向偵測拆分(2.2)。
- 圖結構參數(鏈長、星形入邊數、拔點深度)即練習難度刻度。

### 3.7 心智圖定位

本結構為概念圖(節點加有標籤有向邊)。心智圖是其有損投影,僅作動態視圖;反向重建不成立,故儲存格式必須是圖。(v0.3 起與講稿、投影片同受 P7 統轄。)

### 3.8 邊的生命週期(v0.3 新增,最小版)

- 邊得標記**失效**(stale)——斷邊題或跨來源新證據與既有邊矛盾時,舊邊不刪除(保留證據鏈),標失效並記觸發來源。
- 失效邊不參與圖式抽樣與練習生成。
- 完整邊狀態機列 v0.4 候選 C7,依 P6 掛起。
