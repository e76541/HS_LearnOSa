# 學習管線驗證

## 規範定位

先讀 `Library/CURRENT.md`，解析 `validation` 與本次受測層的穩定 ID；再讀解析結果指向的 canonical 規範。不讀 archive，不寫死實體檔名。

## 三十篇基準

每篇標註文章類型、模塊邊界、語義角色與背景、型別必填欄位、邊真值、應產資產、技能對齊、素材項及對前序節點的命中數；累積繪製重疊率曲線。

## 五類驗證

1. 命題耗損：列原子命題，分概念、機制、量化、類比、敘事計算可由模塊恢復的比例。
2. 邊：方向錯誤率、類型混淆矩陣、長程召回、伏筆穩定性、背景判定一致性。
3. 對齊：錯誤自動對齊率、前五召回、父子誤判率、同義誤建率；偏向人工覆核。
4. 學習效果：三十篇期間至少一組同難度雙文對照；一篇跑全管線、一篇自然閱讀，兩週後用同套問答比較。
5. 演講試跑：二至三篇記素材抽取、背景使用、第二級鷹架、語音選題可靠性，以及流暢度與語義分是否同向。

## 裁決門檻

輸贏與失敗都要記錄，不以單次結果宣稱有效。v0.4 必須同時具備三十篇實際標註與至少兩篇演講場次；未達門檻不得開新規格。

## 產出

交付資料集版本、樣本數、計算方式、各層結果、錯誤案例、人工覆核紀錄、未決問題與可重跑步驟。不得只交總分。

## 驗收

檢查五層耗損、邊與對齊指標、重疊率曲線、兩週對照及演講試跑均有原始樣本與可重算依據；版本門檻未被跳過。
