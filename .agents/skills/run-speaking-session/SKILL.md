# 演講場次

## 規範定位

先讀 `Library/CURRENT.md`，解析 `design-principles`、`module-layer`、`structure-layer`、`practice-layer`、`skill-registry`；再按本次工作讀取解析結果指向的 canonical 規範。不讀 archive，不寫死實體檔名。

## 場次邊界

一次場次等於一條合規鏈，依序執行「備、講、問、記」。本流程是 C4 人工試跑，不宣稱已有自動化產線。

## 備

1. 一頁一模塊，換頁一條邊。頁面只顯示人話短標題、素材錨一行與角落溯源；其餘放備忘稿。
2. 正文回到 `char_span`，銜接回到邊。鏈上素材必須使用；背景素材僅限與鏈端點有邊相連者，並另記使用率。
3. 鷹架：第一級全文講稿；第二級節點標題加銜接任務、邊留白；第三級空白。
4. 鏈上多數節點為 `mastered` 時，自第二級起跳並改用雙來源對照。

## 講

翻頁時間戳作為模塊邊界。語義評分只含鏈節點覆蓋率、邊方向正確性、鏈上素材使用數；背景素材另作表達觀測，不混入語義分。

## 問

1. 問題只可落在單節點、單邊、合法子圖、跨來源候選邊四型。
2. 每問必帶模塊、邊或圖式實例溯源。背景只作語境，不作考點。
3. 優先問邊方向含糊處、弱策略點、已掌握節點的跨來源斷邊。語音比對尚未驗證時，退回後兩項。

## 記

1. 時長、停頓、語速、填充詞率與詞級時間戳只收不評；第一級錄音不計熟悉度。
2. 問答分數獨立記錄。斷邊答案可回填新邊；矛盾時標舊邊 `stale`、保留證據與觸發來源。
3. 記錄本次素材抽取、背景使用、第二級鷹架、提問可靠性及流暢度與語義分關係，供二至三篇試跑驗證。

## 驗收

檢查合規鏈、四幕完整、素材與銜接可溯源、鷹架起點正確、背景未成考點、語義分與觀測值分離、第一級未寫熟練度、所有問題落在封閉世界。
